# Cloudstitch · 중저음 강화 비교실

전체47종과 박격포 A·B 후보2종, 합계49개의 중저음을 이전 풍성 v1보다 한 단계 더 강화한 검수본입니다.

**이전 풍성 v1 WAV ↔ 중저음 강화 v2 WAV**를 비교합니다. 기본값은 동일 RMS 음량 비교이며, 소리의 몸통과 저음의 차이를 듣기 쉽게 두 버전의 전체 음량을 맞춥니다. ‘v1 → v2 비교’ 버튼으로 번갈아 듣고 승인·수정·보류와 메모를 남길 수 있습니다. 검수 JSON과 브라우저 저장은 이전 버전과 분리합니다.

주요 몸통 대역은 재질에 따라148~337Hz에서 약+3~5dB, 저음 shelf는90~118Hz에서 약+1.15~2.5dB 올렸습니다. 새 음이나 긴 저음 꼬리를 추가하지 않고, 기존 질감을 유지하며 따뜻한 중저음의 비중을 높였습니다. 실제 파일에 반영한 처리이며 화면에서 추가 EQ를 거는 방식이 아닙니다.

이전 v1은 `original/`, 새 v2는 `enhanced/`에 WAV로 제공합니다. 두 묶음은 각각16,582,724B이고 길이·프레임·채널은 동일합니다. 새 WAV는44.1kHz stereo PCM16입니다. 출처·주파수 레시피·해시는 `catalog.json`에서 확인합니다.

실제49종 모두 동일 RMS 기준100~350Hz 대역 에너지 비율이 증가했고, 파일검사448/448·플레이어 모의검사43/43·로컬 HTTP검사107/107을 통과했습니다. 이 수치는 필터로 근사한 대역 에너지이며 음색 취향에 대한 청취 승인을 뜻하지 않습니다. 최종 Native 브라우저 검사는 통합 담당의 별도 보고서에 기록합니다.

원본·이전 v1·기존 검수 기록은 보존했습니다. 기존 박격포 발사음의 수정 요청과 A·B 미선택 상태도 유지합니다. 유료 생성·새 의존성 설치·게임 적용은 하지 않았습니다.
