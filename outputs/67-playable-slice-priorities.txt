67. 첫 플레이 시제품 구현 우선순위 — 기획을 검증 가능한 항해로
상태: 제작 인계용 설계. 실제 게임·실행 파일·모델·코드가 구현되었다는 뜻이 아니다. 40번 30~40분 데모 계획을 계승한다. 날짜·인원·비용 견적은 개발 환경 확인 전 제시하지 않는다.

범위의 두 층
기술 시제품은 8~12분 한 구역에서 이동→연결부 절단→회수→장착→다시 이동을 검증한다. 공개 데모 후보는 이 결과가 통과된 뒤 40번의 30~40분 서사 흐름으로 확장한다. 두 범위를 같은 완료 기준으로 섞지 않는다.
첫 기술 시제품에 드론, 모든 동료 임무, 6개 지역, 전체 보스, 48개 지원 장비, 무기 6종을 넣지 않는다. 63번 드론은 확장 후보이고 64번 항구 조연은 이후 단계다.

P0 — 이동과 읽기
입력: 키보드·마우스 이동/조준과 패드 이동/조준. 평면 이동, 55도 기본 카메라, 선택적 기낭 투명화. 함선 1종, 기관총 1종, 적의 느린 포격 1패턴.
산출물: 회색상자 전장과 한 척의 조작 가능한 비행선. 완료 질문: 자신의 전방과 적의 사격 방향을 설명할 수 있는가? 예고를 보고 회피할 시간이 있는가? 기낭이 포탑·연결부를 가리지 않는가? 실제 관찰 전 통과로 표시하지 않는다.

P1 — 한 부모 연결 구조
루트 선체, 기낭, 기본 엔진, 굵은 연결 골조, 측면 갑판, 함포, 보조 엔진. 부품 ID·내구도·부모 ID를 갖는다. 65번 징세정의 연결 골조를 절단하면 갑판과 자식들이 하나의 묶음으로 분리된다. 함포만 파괴하면 엔진은 남는다.
완료 조건: 두 결과가 동일 규칙으로 반복 재현되고, 폭발 중복 피해나 분리된 적 함포의 계속 사격이 없어야 한다. 이것은 개발자가 확인할 기능 검수이며 초행자 이해 여부는 별도 관찰한다.

P2 — 회수와 편집
갈고리 1종, 분리 묶음의 남은 내구도 유지, 회수 시 소유 변경, 함선 편집 미리보기. 소켓과 부모 부품을 고른 뒤 전체 중량·양력·전력을 확인하고 장착한다. 기존 50번 기본 함선 예산을 기준으로 한다.
완료 조건: 같은 부품을 두 번 회수해 복제할 수 없고, 부모 제거 시 하위 묶음이 미리 표시되며, 회수만으로 자동 장착되지 않는다. 직접 붙인 부품 때문에 조작감·사격 구성이 바뀌는지 확인한다.

P3 — 위험과 복구
양력 부족 경고, 7초 초기 유예와 심각 사고 최소 3초 대응, 장갑 투하·수리·철수. 수치는 19번 초기 가설을 그대로 시작점으로 사용한다. 실제 조작 시험에서 시간이 부족하면 먼저 예고·메뉴 접근·복구 경로를 조정한다.
전력 과부하는 지원 장비 우선순위로 처리하며 기본 조타 입력을 뒤집지 않는다. 일시정지 메뉴는 위험 타이머를 멈춘다. 엔진 상실 후 무한 표류하지 않고 비상 이동 또는 재시도를 제공한다.

P4 — 항구와 정산
수리·편집·출항 3기능만 있는 간단 허브. 66번 요약 화면에서 실제 자원 변동과 미지불 견적 분리. 미션 정산 ID로 중복 지급 방지. 재시작 시 마지막 안전 경계 상태를 복원한다. 저장 실패를 사용자에게 알리고 성공으로 위장하지 않는다.
완료 조건: 출항→전투→회수→귀환→수리→재출항이 두 번 이어져도 자원과 부품이 일관된다. 저장·불러오기 중단 시나리오를 별도 확인한다.

P5 — 한 사람과 한 기억
기술 검증 뒤 마라의 짧은 대사와 기억이 남은 포탑 하나를 추가한다. 56번 누리 전체 임무나 59번 마라 개인 임무를 압축해 정사를 바꾸지 않고, 데모용 짧은 발견으로 설계한다. 외부 모델과 음성 없이 자막·소품·한 번의 노크로 호기심을 검증한다.
완료 질문: 플레이어가 다음 항해에서 확인하고 싶은 것을 말할 수 있는가? 기억 장비를 단순 추가 피해 아이템으로만 이해하는가? 설명이 길어 전투를 잊게 하는가?

제작 작업 묶음과 의존성
입력/카메라→모듈 판정→적 패턴→회수→편집→자원/정산→저장→짧은 서사 순서. 아트는 회색상자와 같은 충돌·소켓 위치를 유지하는 표준 함선 세트부터 교체한다. 분위기용 보스 전장 아트가 P1 판정을 대신하지 않는다. 사운드는 회피 예고·분리·회수 완료·경고 4기능부터 만든다. 음악과 전체 대사 녹음은 뒤로 둔다.

테스트 결과 기록 양식
빌드 ID / 날짜 / 입력 방식 / 해상도 / 변경점 / 실제 관찰 / 도움 제공 지점 / 재현 절차 / 다음 수정 / 미해결 한계. ‘예고가 잘 보인다’ 대신 ‘두 번째 포격 전에 오른쪽으로 이동했고 원인을 설명했다’처럼 관찰 행동을 적는다. 테스트 참가·녹화·외부 분석 도구는 현재 실행하지 않았다.

스토리보드 6컷
1. 단순 회색상자 전장에서 이동·사격하는 기본 비행선.
2. 색을 최소화한 연결부와 한 덩어리로 분리되는 외부 갑판.
3. 갈고리 회수 뒤 소켓에 부품을 붙이는 편집 미리보기.
4. 양력 경고를 보고 장갑을 투하해 안정시키는 장면.
5. 간단 항구에서 정산·수리 후 다시 출항.
6. 같은 흐름을 최종 재질로 바꾼 한 장면과 기억 포탑의 작은 빛.
무드보드는 제작 단계의 대비를 위한 참고 이미지다. 회색상자 그림도 실행 가능한 프로토타입이 아니다.
