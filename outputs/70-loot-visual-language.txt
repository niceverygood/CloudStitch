70. 전리품 시각 언어 — 상태·기억·대가를 따로 읽는다
상태: 11·26·46·51·66번 규칙의 제작 명세. 생성 이미지의 작은 문구·수치는 게임 데이터가 아니다.

세 축을 혼동하지 않는다
물리 상태: 온전/손상/파괴. 기억 여부: 일반/기억 있음/핵심 유물. 조사 상태: 미확인/확인/봉인/이름 돌려줌. 서로 독립된 축이다. 손상된 기억 함포, 온전한 일반 엔진, 봉인한 기억 장갑이 모두 가능하다. ‘더 희귀하니 더 새것’ 또는 ‘파란 빛이 있으니 저주 활성’처럼 단순화하지 않는다. 별도 희귀도 단계 수·드롭률은 아직 확정하지 않는다. 기존 희귀도 표현은 테두리 형태와 문구를 병행하되 기억 분류를 성능 등급으로 취급하지 않는다.

물리 상태 표현
온전: 기능 부품이 남고 판금이 닫혀 있으며 일정한 작업등. 손상: 벌어진 판금·기낭 덧댐·불규칙한 연기, 카드에 손상 문구와 내구도 막대. 파괴: 기능 부품이 사라진 잔해이며 장착 버튼 없음. 검은 연기만으로 모든 상태를 가리지 않는다. 기낭 천의 찢김과 엔진의 균열은 재질에 맞게 다르게 만든다.

기억과 핵심 유물
일반 모듈 카드: 단일 직선 테두리와 종류 아이콘. 기억 모듈: 같은 기본 카드에 작은 접힌 이름표 아이콘과 이중 모서리. 고유 이름과 ‘기억 있음’ 문구. 희미한 차가운 입김은 최초 발견과 안전 조사 중에만 짧게 나타나며 전투 표적의 시야를 가리지 않는다. 핵심 유물: 문서 잠금 아이콘·이야기 항목. 판매·분해 목록에 들어가지 않는다. 자원은 고철/연료/봉인 천 아이콘과 수량으로 표시한다. 금화·보석 화폐를 추가하지 않는다.

미확인과 확인
미확인: 접힌 물음표가 붙은 이름표, ‘대가 미확인’. 이미 알 수 있는 무게·내구도·필요 전력은 숨기지 않는다. 대가의 범주는 열 축적/은폐 감소/견인 둔화처럼 공개한다. 모르는 효과를 가짜 확정 수치로 보여 주지 않는다.
확인: 이점과 대가를 좌우 동일 크기 카드로 표시. 이점만 큰 금빛 제목으로 강조하고 대가를 작은 회색 글씨로 숨기지 않는다. 장착 전 경고는 한 번 요약하고 상세를 열 수 있다.

봉인 상태
천을 두른 실물 이름표, 봉인 매듭 아이콘, ‘고유 효과 잠김’. 고유 이점과 저주가 함께 잠기며 기본 성능만 남는다. 효과가 잠긴 상태를 고장·물리 파괴와 혼동하지 않는다. 봉인 장비는 기본 성능 사용 가능. 해제는 안전 항구에서 선택하며 갑작스러운 자동 저주 재활성화를 만들지 않는다.

이름 돌려주기
확정 화면에 ‘물건은 떠납니다’와 대체 설계도·기록·관계 보상을 함께 보여 준다. 장비를 상실하는 선택을 단순 확인 버튼으로 처리하지 않는다. 확인 이후에는 도감에서 이름과 기록을 볼 수 있으나 장착 목록에는 남기지 않는다. 56번 누리의 선택과 모순되는 무결점 최상위 보상 강요를 만들지 않는다.

전투 중 최소 정보
분리 모듈에는 종류·상태·크기만 표시. 기억 아이콘은 작게 붙이고 자세한 이점/대가는 일시정지 또는 회수 후 확인한다. 희귀도 빛기둥은 사용하지 않는다. 위험 예고와 같은 주황색 외곽선으로 전리품을 강조하지 않고 크림 외곽선·종류 아이콘을 쓴다. 적 부품과 자기 부품은 아이콘·출처로 구분해 반복 회수 이득 오해를 줄인다.

아이콘과 입력
분류·상태·조사 아이콘은 모양 차이를 유지한다. 색약 모드에서 의미 손실이 없어야 한다. 작은 카드에 아이콘을 과도하게 쌓지 않고 대표 상태 1개와 펼쳐 보는 상세로 압축한다. 화면 읽기용 명칭은 ‘기억 함포, 손상, 대가 확인됨’처럼 순서를 통일한다. 실제 스크린리더 지원은 기술 검토 전 구현되었다고 주장하지 않는다.

스토리보드 6컷
1 같은 일반 엔진의 온전·손상·파괴 3상태 비교.
2 일반 함포와 이름표가 있는 기억 함포, 직선/이중 모서리 카드 비교.
3 미확인 카드가 작업대 조사 후 이점·대가 동일 크기 카드로 열림.
4 봉인 천 매듭이 이름표를 감싸고 고유 효과 잠김 표식이 보임.
5 이름표와 물건을 돌려주고 설계도·기록이 남는 조용한 선택 장면.
6 전투 회수의 간결한 외곽선과 항구 상세 카드의 정보량 비교.

검수와 구현 경계
텍스트만 읽어도 상태를 이해할 수 있는가? 봉인과 파괴를 혼동하는가? 기억 아이템을 무조건 상위 등급으로 생각하는가? 대가 미확인을 설명 없이 장착시키는가? 초행 테스트에서 확인할 질문이다. 현재 이미지와 문서는 UI·장비 VFX 참고이며 실제 드롭 테이블·감정 비용·희귀도 확률은 별도 데이터 검토가 필요하다.
