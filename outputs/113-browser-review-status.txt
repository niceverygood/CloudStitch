브라우저 시도와 한계
내장 브라우저의 file URL 열기 요청은 시간 초과로 끝났다. 연결 상태를 다시 확인했고, Chrome의 같은 로컬 file URL 요청은 브라우저 보안 정책상 허용 프로토콜이 http/https로 제한되어 거절되었다. 이 거절 이후 우회 서버·다른 브라우저 표면·원시 브라우저 명령으로 같은 결과를 시도하지 않았다. 실제 렌더링·검색 입력·문서 펼치기·이미지 로딩의 브라우저 상호작용 검증은 미완료다.
브라우저 검토 준비 중 Python 실행 명령은 설치되지 않은 Windows 별칭으로 종료되어 서버가 시작되지 않았다. 관련 백그라운드 서버 없음.

사용 방법
ZIP을 한 폴더에 모두 해제하고 FINAL-game-design-2026-10-17.html을 사용자가 직접 브라우저로 열 수 있다. 파일은 같은 폴더에 유지한다. 검색·문서 펼치기·내부 바로가기는 HTML 기능으로 작성되었지만 도구에서 실제 동작을 확인했다는 주장과 구분한다.
