21 무기 체계·수치·강화의 역할
프로토타입용 가상 단위. 실제 게임 측정치 아님. 거리U는 배 길이 약10U인 전투 공간 기준. 모든 수치는 테스트 후 변경.

공통 규칙
무기는 소켓·무게·전력·사거리·회전속도·사각을 갖는다. 탄환은 보이는 궤적과 충돌. 기본 탄약은 장전 시간으로 관리하고 임무 도중 소모 탄약을 매발 구매하지 않는다. 특수탄은 스킬이나 한정 소모품으로 구분. 자원 경제에서 기본 사격을 무료로 두며, 연료는 항로 및 과출력 예산.
장갑은 단순 고정 차감으로 소형 무기를 완전히 무력화하지 않도록 최소 피해 비율을 둔다. 관통력은 장갑 등급과 비교하는 초기안. 함포가 무조건 최고 DPS인 대신 무게·회전·사거리·순간 화력 역할을 구별.

기본 6종, 단계1 수치
기관총: 탄당8, 초당5발, 사거리45U, 회전90도/초, 무게8, 전력2. 이론DPS40. 장점은 추적·지속 압박·제압 발동, 약점은 장갑 효율. 연사열100 도달 시1.5초 냉각, 실전 지속DPS는 이론보다 낮음. 중장갑 상대로 최소30% 피해 초기값.
함포: 발당90, 장전3초, 사거리60U, 회전35도/초, 무게18, 전력3. 이론DPS30. 장점은 한 발의 약점 파괴·중장갑 대응, 약점은 빠른 소형 적과 근거리 사각. 일반탄은 한 대상, 철갑 특수탄은 제한 관통.
박격포: 발당70, 장전4초, 사거리25~70U, 폭발반경8U, 회전30도/초, 무게20, 전력3. 단일대상 이론DPS17.5. 다중 모듈·느린 밀집 적에 강함. 낙하 전 표식, 비행시간으로 회피 가능. 근거리 최소사거리 있음.
작살포: 명중피해15, 장전5초, 사거리35U, 회전45도/초, 무게12, 전력4. 피해보다 견인. 최대 견인질량은 장치 등급에 의해 제한. 적을 당기면 내 배도 힘을 받지만 입력 반전은 없음. 케이블은 공격하거나 거리로 끊을 수 있음. 과도한 장력은 경고 뒤 자동 해제.
사슬탄: 두 탄환 합산피해30, 장전5초, 사거리40U, 회전40도/초, 무게14, 전력2. 명중 엔진의 출력25% 감소3초, 같은 효과 갱신만. 선체 맞으면 피해만, 부위 정밀도가 가치. 스킬 사슬탄 사격은 별도의 특수 사격 강화이며 기본 무기의 둔화와 합산하지 않고 강한 값 사용.
화염방사기: 초당피해24, 사거리18U, 원뿔각30도, 회전60도/초, 무게12, 전력4. 점화 상태 초당4 피해3초, 동일 출처 중첩 없음. 장갑 직접 피해 낮고 외부 목재·노출 장치에 강함. 최대 연속분사3초 뒤 냉각2초. 바람에 시각 효과가 휘어도 실제 판정 방향은 명확한 원뿔로 유지.

강화 4단계 원칙
단계1 기능 학습. 단계2 편의와 안정성: 추적·장전·발사각. 단계3 역할 강화: 장갑관통·범위·견인질량 등. 단계4 플레이 변화: 다연장 지속탄막·중공성탄·쌍열 곡사·이중 작살·복수 사슬탄·쌍열 화염.
무게 배율 초기안 1/1.25/1.6/2.1. 전력은 계단식 증가. 총 화력은 크기 증가보다 완만하게 올라 낮은 단계 여러 개도 유효. 단계4 때문에 소형 선박 운용이 사라지지 않게 장착 크기 제한을 공개.
기관총 단계별 방향: 발사속도보다 과열 관리와 급탄 안정 향상. 함포는 한 발 피해·관통, 박격포는 범위·다중 장전, 작살포는 무게·두 대상 인양, 사슬탄은 제어 범위·다중 발사, 화염은 분사 유지·폭 증가.

상성 예시
빠른 정찰선: 기관총/사슬탄. 중장갑 봉쇄선: 함포/약점 사격. 밀집 산업 장치: 박격포. 인양선: 케이블과 윈치 집중. 목재 외부 갑판: 화염. 온전한 포탑 노획: 연결부 타격+작살. 모든 적을 특정 무기 없이는 절대 못 잡는 경직된 열쇠-자물쇠 설계는 피함.

추가 무기 후보, 후속 확장
정밀포: 긴 조준과 부위 관통. 산탄포: 근거리 부품 다중 타격. 로켓: 느린 다중 탄도와 요격 가능. 쇠뇌: 조용한 기습과 저전력. 요격포: 피해보다 발사체 방어. 고철 발사기: 자원 소모 광역 제압. 이들은 기본6종 재미 검증 뒤 추가, 초기 제작범위에 한꺼번에 포함하지 않음.

6장면 무드보드
정찰선을 추적하는 기관총 / 장갑 연결부를 깨는 함포 / 도크 위 곡사 폭발 / 적의 엔진을 붙잡는 작살 / 프로펠러에 감기는 사슬 / 근거리 외부 갑판 화염. 각 장면 발사각·거리·효과를 작은 선 그림으로 전달, 숫자는 기획서에만.

확인할 측정
명중률·부위 파괴 시간·이론 대비 실전DPS·노획 성공률·재장전 중 회피 빈도·한 무기의 점유율. 이론DPS 하나로 밸런스 결론 내리지 않음.
