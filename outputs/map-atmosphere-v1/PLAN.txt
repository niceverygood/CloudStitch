Cloudstitch · 항로의 작은 세계 / 환경 에셋 검토안 v1
기준: 2026-10-18 사용자 직접 요청 및 첨부 항로 생활 무드보드

의도
최신 공통10배 표현 기준을 반영해, 과감한 큰 형태·중간 기능 덩어리·작은 생활층·움직임의 시차를 함께 재설계한다.
이전세모듈은 baseline-r1로 보존하고 대표6종을 동일카메라/배치/재생시점에서 실제 비교한다. 체감 목표의 달성은 사용자 미술 검토로 판단한다.
비행선 주변을 단순한 빈 하늘 대신 풍성한 자연과 생활의 흔적으로 채운다.
큰 공중섬 실루엣→구름의 층→새와 잎/천의 작은 움직임→황동·목재 생활 소품 순서로 읽히게 한다.
색만 바꾼 섬 반복을 피하고 너비/높이/실제 빈 공간/뿌리/구조 기능을 구별한다.
주항로와 조준점 주변에는 쉬는 공간을 남긴다. 장식 밀도는 피해·슬롯·충돌 범위와 무관하다.

기획 묶음과 사용 제안
01~06 공중섬: 뿌리 정원 / 초승달 통로 / 두 겹 아치 / 빗물 계단 / 난파 목재 정원 / 고요한 석재 테라스.
  넓고 낮은 쉼터·빈 통로·높은 협곡·세로 낙수·생활 잔해·조용한 외곽의 서로 다른 실루엣.
07~08 식생: 바람에 누운 수관나무 / 매달린 꽃·덩굴 정원.
  근경의 풍성함과 장소의 바람 방향을 보여주는 시각 요소. 실제 풍압 판정은 없다.
09~12 구름: 햇살 이불구름 / 골짜기 안개리본 / 상승구름 / 먹구름 모루전선.
  넓은 운해·얇은 수평층·수직 흐름·짙은 먼 전선. 같은 구형 덩어리의 색변형으로 채우지 않는다.
13~16 새: 흰깃갈매기 / 바람꼬리제비 떼 / 능선 황금수리 / 벼랑 꽃가지새.
  부리·몸 비율·날개 폭·깃·꼬리·무리 수·박동을 구별한다. 새를 적·자원·필수 단서로 확정하지 않는다.
17~24 항로와 생활: 우편 부양낭 / 수선 기낭 / 피뢰주 / 화물 크레인 / 계류등 / 풍향 리본 / 작은 식사 갑판 / 별빛 풍등.
  첨부의 봉제선·가방·황동 윈치·등·작은 차양·찻잔 같은 생활 밀도를 독자적 소품으로 옮긴다.

지역 배치 후보(이번에 실제 배치한 결과가 아님)
종항 잔해해역: 뿌리 정원·난파 목재·갈매기·우편·수선·식사 갑판.
청록빛 상승기류 협곡: 초승달·아치·빗물·상승구름·제비·수관나무·풍향 리본.
천둥 폭풍벽: 모루전선·피뢰주·계류등. 피뢰주를 플레이어 번개 무기로 등록하지 않는다.
쇠갈비 공업지대: 크레인·수선대·목재 잔해. 민간 작업공간과 적 기지를 구별한다.
이름 없는 함대의 저층 안개: 긴 안개·낮은 계류등·멀리 보이는 난파 외형.
황궁 검은 천정: 조용한 석재 외곽과 낮은 등. 새 도시·상점·왕실 비밀 공개는 추가하지 않는다.

정사·원본
기존6지역, 기존96월드 자산/7조립 장면, 선택 비행선과 시작화면은 읽기 참조만 한다.
이번3장 무드보드의 풍경/수량은 확정 맵 지리·엔진 치수·실제 규칙이 아니다.
첨부 인물/장면을 게임의 새 NPC·미션·종 사건으로 채택하지 않는다. 종 도난/빈종틀의 증거 순서를 보존한다.

검토 순서
리뷰창에서 24종의 큰 형태와 재료 차이를 보고, 새/천/구름의 움직임을 재생한다.
수정할 대상은 개별ID로 지정한다. 사람의 미술 승인 뒤 엔진용 밀도·피벗·충돌·LOD·실제 맵 배치를 별도로 결정한다.
