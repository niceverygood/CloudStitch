Cloudstitch · 클라우드스티치
6개 판 브라우저 교전 시제품 v1
기준일: 2026-10-18

열기
저장소 루트에서 python3 -m http.server 8840 --bind 127.0.0.1 을 실행한 뒤
http://127.0.0.1:8840/outputs/encounters-v1/ 에 접속한다.
기존 함대의 GLB를 ../fleet-v1/ships/ 상대 경로로 읽으므로 저장소 루트를
서버로 열어야 한다. 이 HTML을 file://로 직접 여는 방식은 지원 범위가 아니다.
실행 코드/Three.js는 로컬 번들이며 외부 CDN·생성 API를 사용하지 않는다.

조작
WASD/방향키 이동, 마우스 왼쪽 누르기/J 사격, Space 긴급기동,
Esc/버튼 일시정지, 자동 조준 설정, 터치 조이스틱/사격/기동을 제공한다.
선체 체력0이면 패배하며 같은 판을 처음부터 다시 출항할 수 있다.

구성
지역6개를 별도6개 플레이판으로 재편성했다.
각 판: 일반 적 → 중간보스 → 안전 정비 → 후반 일반 적 → 최종보스 → 승리.
일반 적36회 + 중간보스6회 + 최종보스6회 = 전체48회 등장이다.
이는 스폰 횟수이며 고유 함선/모델48종을 의미하지 않는다.

1 종항 잔해해역: 일반2+2 / 소형 장례 경비선 / 종을 삼킨 자
2 청록빛 상승기류 협곡: 일반3+3 / 협곡 관문 지휘정 / 사슬협곡 인양 지휘선
3 천둥 폭풍벽: 일반3+3 / 폭풍 견인대장 / 폭풍 봉쇄 지휘선
4 쇠갈비 공업지대: 일반3+4 / 도크 수리 지휘정 / 수석 조선공의 지휘함
5 이름 없는 함대의 저층 안개: 일반3+4 / 안개 돌격대장 / 죽은 함대 왕의 배
6 황궁 검은 천정: 일반3+3 / 황궁 외곽 종 관문함 / 마지막 들숨·봉인 심장

범위와 한계
모든 보스는 정사 외형을 참고한 교전 역할 변형(prototypeCommander)이다.
원문 보스의 전체 장치/대사/기억 반환/구조/결말은 구현하지 않았다.
체력0은 이번 교전의 무력화이며 정사 인물의 사망이나 캠페인 완료가 아니다.
중간 정비의 무료 완전 수리는 이번 교전 시험용 구제이며 정사 경제 규칙이 아니다.
정비 뒤 사용자가 후반 항로 버튼을 눌러야 전투를 계속한다.
난이도3단계의 배율은 시제품 가설이며 모든 난이도에서 돌진1.2초·광역1.5초
최소 예고와 전반1/후반2 큰 공격 토큰을 유지한다.

판별 승리 표시는 localStorage의 cloudstitch-encounters-v1-wins에만 저장한다.
전투 중 상태, 부품, 자원, 캠페인 이어하기 저장은 없다.
부품 연결부 절단/회수/소유권/화물/제작/장착/양력/경제/정산/P1~P4 순환,
전체 캠페인, 최종 엔진·플랫폼·미터 스케일·출시 성능 확정은 후속이다.
기존 기획·함대 원본과 리깅 자산은 보존하며 새 유료 생성 호출은 없다.
