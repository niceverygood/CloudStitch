Cloudstitch · 2탄 적군 기지 무드보드 01
2026-10-19 / Asia/Seoul

사용자 요청: 2탄 적군 기지를 만들되 먼저 무드보드부터. 1탄과 완전히 다른 세계관.
산출물: moodboard.png / 생성 프롬프트 prompt.txt / manifest.json.
제작 방식: built-in image_gen 1회. CLI/API fallback과 새 Meshy 모델 생성 없음.

시안명: 적조의 왕관. 확정 정사·공식 지역명·세력명 변경이 아닌 새 아트 제안이다.
1탄의 철갑 선체·유럽식 첨탑·청록 지붕 대신, 거대한 나선 조개와 뼈 방벽,
붉은 산호 포대, 진주층 테라스, 밧줄 회랑, 해초와 생체발광의 공중 심해 문명을 제안한다.
구름 위에 떠 있는 기지이며 수중 맵으로 확정하지 않는다.
손그림 같은 입체감과 수공예 재료를 유지하고, 10배 표현 방향은 거대한 포식자 실루엣,
겹겹의 거주 구역과 교량/포대/항구, 작은 배와 인물의 규모 대비, 풍부한 재료층으로 적용했다.

실제 생성 이미지 직접 확인: 전체 기지 1개 + 일관된 세부 장면 3개 + 팔레트.
제목/패널 글자, 나선 패각·뼈 관문·산호 포대·보랏빛 구름·진주층/밧줄 재료를 확인했다.
1탄의 탑군과 철갑 선체를 반복하지 않는 실루엣과 건축 구조다. 일부 직물/난간/밧줄은 작품 공통 재료로 남는다.
원화나 기존 1탄 모델/리뷰는 덮어쓰지 않았다. 사용자 최종 미술 승인 대기.
정지 콘셉트 이미지다. 실제 3D/전투/지역 규칙/무장 수/크기/소켓 구현은 이 단계에서 만들지 않았다.
