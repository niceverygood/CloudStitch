40 첫 데모와 플레이테스트 설계

데모 목표
30~40분 안에 '전투로 부품을 떼고, 회수해 배를 바꾸고, 그 부품의 기억 때문에 다음 항해가 궁금해진다'를 경험. 캠페인 전체·커스터마이즈 전부·엔딩은 데모에 포함하지 않음.

데모 흐름
0~2분 타이틀·기본 프리셋·자막 설정, 긴 생성 화면 건너뛰기 가능.
2~14분17문서의 프롤로그 축약, 마라 구조와 종항 입항.
14~20분 종항 정비·엔진 장착·첫 기억 감정·종지기 의뢰.
20~32분 잔해 삼거리 인양 임무, 기관총/함포/작살포3종을 사용하거나 선택. 약점 분리와 무게 선택.
32~38분 소형 장례 경비선 미니보스, 포격 예고→후방 약점→노획. 거대 첫보스 전체는 티저로만, 본편 보스 난이도와 혼동하지 않음.
38~40분 귀환 정산, 포탑에서 낯선 이름, 닫힌 해치의 한 번 노크. 다음 항해 예고와 데모 종료. 로딩·실패·조사로 실제 시간 변동.

개발 게이트
G1 기본 이동·조준·장전이 재미있는가, 회색상자 적2종.
G2 연결부 분리·노획·재장착 결과가 이해되는가, 모듈5종.
G3 무게·양력·수리 선택이 의미 있는가, 경제 최소값.
G4 30분 흐름에서 이야기와 전투가 연결되는가, 기억장비1개와 마라.
G5 UI·패드·자막·저장·재시도가 완주 가능한가.
아트 풀세트 이전 G1~G3 검증. 각 게이트 실패 시 해당 규칙을 고치고 기능만 늘리지 않음.

플레이테스트 구성
첫회6~8명 소규모 탐색, 결과를 통계적 확정으로 과장하지 않음. 함선 게임 경험자와 초보, 키보드와 패드, 접근성 설정 사용자 포함 목표. 실제 참가자 모집·외부 연락은 이번 기획 범위 밖, 실행하려면 별도 요청 필요.
처음10분 설명 없이 관찰, 막히면 도움을 준 시점 기록. 테스트 후 구체적 질문: 왜 피격했나? 어떤 부품을 노렸나? 무엇을 붙였나? 기억 장비의 대가는? 다시 하고 싶은 행동은?

기록 후보
첫 회피까지 시간, 첫 약점 파괴, 회수 놓침, 장착 취소, 양력 경보 이해, 분해 실수, 재시도 횟수, 메뉴 체류, 기억 장면 스킵, 끝난 뒤 기억하는 목표. 외부 분석서비스를 자동 붙이지 않음. 초기 로컬 테스트 로그와 동의된 녹화만 후보.
관찰 기준: 대부분 첫 인양을 도움 없이 완료, 위험 예고를 설명 가능, 최소1회 자발적 장비 선택, 막힌 상태에서 복구 경로 발견. 비율 목표는 초기 가설이며 작은 표본에서 성공 선언 금지.

범위 고정
함선1계열+모듈변형, 무기3, 적3, 미니보스1, 지역2, 마라1, 기억1, 임무2, 임시 스킬9. 연구는 잠긴 전체 트리 대신 의미 있는2개 해금만. 스킬 포인트는 짧은 임무에서8점 완성을 강제하지 않고 데모 시험용 프리셋으로 궁극기를1회 체험 가능.

무드보드6컷
시작 / 첫 회피 / 첫 인양 / 항구 장착 / 미니보스 약점 / 기억과 종료. 진행 시간은 제작 목표 안내, 실제 테스트 결과처럼 표시하지 않음.
