45 UI 상태·전환·저장·재시도 명세

전역 화면 흐름
시작 설정→타이틀→슬롯선택→새항해/계속→항구→출항준비→항로→임무→정산→항구. 임무 안 일시정지→화물/기술/기록/설정 후 원래 시점으로 복귀. 대화 중 화면을 닫으면 같은 문장과 선택 상태 복원. 기록 재현은 별도 임시세션 표식 유지.

타이틀 상태
저장없음: 계속하기 비활성, '저장된 항해가 없습니다'. 슬롯빈칸: 새항해. 슬롯사용중: 인물·배명·막·최근항구·시간·저장시각. 불러오기 전 버전차이·백업필요 여부 안내. 스포일러 이미지 대신 당시함선 실루엣.
슬롯덮어쓰기: 삭제될 항해명과 마지막시각, 취소 기본포커스. 빠른 연속입력으로 확인을 건너뛰지 않음. 실패한 불러오기를 새로운게임으로 자동 대체하지 않음.

출항준비 상태
정상: 목표·항로·적정보·예상날씨·장비·화물·연료 요약, 출항버튼.
경고: 양력여유작음/미수리/선택대화보류/지원장비미장착. 경고는 출항 가능하면 허용하고 이유 명시.
불가: 엔진없음/핵심양력부족/필수임무도구없음. 무료 임대나 정비로 해결하는 직접 링크. 막연한 '조건미충족' 금지. 주임무는 기본 운항 지원으로 막힘 해소.
확정 뒤 로딩 중 출항버튼 중복입력 잠금, 취소 가능한 단계와 불가 단계 구별.

저장 범위 결정 초안
임무 전체 모든 작은 물리 파편의 프레임상태를 보존하지 않음. 핵심선체·장착그래프·현재내구도·화물·스킬·재사용·소모품·임무단계·적핵심상태·중요잔해·관계플래그를 구간스냅샷으로 저장. 재개는 최근 안전경계에서 재구성, 화면에 '최근 안전 지점에서 재개'를 명시.
임무중 종료 시 현재상태를 그대로 완전복원한다는 약속은 초기안에서 보류하고 안전경계복귀로 통일. 구간 시작 이후의 확정선택·보상중복은 트랜잭션ID로 관리하는 기술설계 후보. 저장 구현 전 세부 검증 필요.
기본 자동저장: 항구입항·출항직전·임무구간완료·보스단계시작·중요선택직전. 안전수동저장과 자동3백업. 보스재시도는 단계시작 스냅샷의 장비·소모품·자원 복원.
저장중표시: 작은 아이콘과 짧은 문구, 긴 작업이면 진행상태. 저장완료 전 강제종료 위험 경고. 파일쓰기중 실패는 기존 저장을 덮어버리지 않는 원자적 교체와 백업 후보.

패배 화면
배 파괴 장면은 짧고 스킵. '핵심 선체 파괴 / 양력 회복 실패 / 보호 대상 상실'처럼 실제 원인. 선택: 최근지점 재시도 / 장비와 설정 / 항구복귀. 재시도버튼 기본포커스, Enter연타가 연출과 메뉴 선택을 함께 넘기지 않음.
조건상 장비변경 가능한 안전구간이면 편집 허용, 보스단계 중간은 임시정비 메뉴에서 소켓 변경 범위 제한. 언제든 설정변경으로 접근성 확보.

거래·제작·분해
보유부족: 부족한자원과 얻을방법. 장착불가: 소켓크기·회전공간·전력 등 구체조건. 분해는 실제목록+획득자원, 기억장비 별도보호. 동일확정이 여러번 처리되지 않음. 되돌리기는 장착/도색 편집에 제공, 분해·판매는 확정전 확인. 정산보상은 고유임무완료ID로1회 지급.

로딩과 오류
지역전환: 마지막 장비사진·스포일러 없는 항해팁. 읽으라고 불필요한 로딩을 늘리지 않음. 저장실패: 오류문구·재시도·다른슬롯·백업, 기술로그는 일반 플레이흐름에서 숨기고 지원항목에 제공. 컨트롤러분리: 즉시 일시정지와 재연결/키보드안내.
게임파일·클라우드·플랫폼오류는 구현플랫폼 확정 후 별도. 현재는 UX 요구사항이며 실제 저장 안정성 검증 아님.
