index.html에서 우리편과 적군, 보스를 두 척씩 나란히 비교하세요.
각 칸에서 배를 고르거나 전체 카드의 '왼쪽에 놓기 / 오른쪽에 놓기'를 누릅니다.
'이 배를 3D로 보기'는 한 척만 불러오며, 닫으면 해당 뷰어를 제거합니다.
최신62항목은 같은 배의 이전v1 외형도 열 수 있습니다.

전체 카탈로그71항목과 이미지71개를 모두 제공합니다.

이 수는 장비/상태/역할/시설을 포함하며 고유 정사 함선71종이 아닙니다.
우리편12 / 적군19 / 중립·상황별29 / 기록·디자인참고11로 분류했습니다.
함대왕, 협상 라이벌, 민간·구조 대상의 관계는 개별 설명을 확인하세요.

초기 고밀도 생성 원본9개는 페이지 하단에 별도 이미지를 보여줍니다.
위9대안의 리그 해석본과 다른 출력이며 같은 디자인을 새9종으로 세지 않습니다.
기존 원본 GLB 다운로드와 원본 갤러리로 연결합니다.

6판의 중간보스/최종보스12슬롯은 현재encounter의 실제 편성입니다.
2·3판 등에서 기존 일반선이 맡은 보스 역할을 신규 정사 보스로 바꾸지 않습니다.
정사 지역 보스와 미정 슬롯은 별도 설명으로 남겼습니다.
READY-2에서는 정사 중간/최종12칸·미정8칸과 조선소 지휘함 구성요소1행을 표시합니다.

이미지는 각각 화면에 맞춘 크기입니다. 실제 크기/미터/게임 밸런스가 아닙니다.
새 모델·전투·진행·저장·소켓/충돌 기능은 이 비교판에서 추가하지 않았습니다.
기존v1/v2 모델과뷰어, 원화, 동결된 검증 산출물은 수정하지 않았습니다.
