# Cloudstitch · 풍성한 소리 비교실

기존 효과음 47종과 박격포 발사 A·B 후보 2종을 모두 보강한 **49개 새 WAV 검수본**입니다. 원본 MP3는 그대로 복사해 함께 제공합니다.

`node tools/audio/rich-v1/serve.mjs 8866` 실행 후 <http://127.0.0.1:8866/outputs/audio-rich-v1/>에서 듣습니다.

1. 소리를 선택하고 **원본 → 새 버전 비교**를 누릅니다.
2. 기본값은 같은 RMS 음량 비교입니다. 단순한 음량 상승보다 질감·무게·공간의 차이를 확인할 수 있습니다.
3. 승인·수정 요청·보류와 메모를 남기고 검수 JSON을 내보낼 수 있습니다. 기존 검수실 기록과 별도로 저장합니다.
4. **세 소리의 균형**에서 경고·피격·발사가 함께 들릴 때 식별되는지 확인합니다.

무기·충돌에는 짧은 재료 공명과 압력감, 천·바람에는 부드러운 마찰층과 공간, 기계에는 몸체 울림을 추가했습니다. 저음은 원래 소리의 순간에 맞춰 짧게 붙이고, UI·경고·환경음에서는 더 억제했습니다. 화면에서 추가 EQ를 거는 방식이 아니라 새 WAV 자체에 반영했습니다.

박격포의 기존 발사음은 사용자 수정 요청 상태입니다. A·B 후보는 아직 선택되지 않았으며, 이번 보강도 음색 승인을 의미하지 않습니다.

원본은 `original/`, 새 파일은 `enhanced/`, 출처·개별 처리·해시는 `catalog.json`에 있습니다. 새 파일은 44.1kHz stereo PCM16 WAV이며 총 16,582,724B입니다. 추가 유료 생성은 없고 게임에는 아직 적용하지 않았습니다.

실제 파일 검사 592/592, DSP 검사 26/26, 플레이어 모의 검사 43/43, 겹침·모노 검사 31/31, 로컬 HTTP 검사 107/107을 통과했습니다. 수치 검사는 주관적인 풍성함·극적 느낌·저음 취향에 대한 청취 승인을 대신하지 않습니다. Native 브라우저의 최종 재생 검사는 별도 보고서로 구분합니다.
