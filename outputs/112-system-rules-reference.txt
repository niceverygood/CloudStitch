112. 시스템 기준 표와 미확정 값
이 문서는 기존 기능을 읽기 쉽게 정리한 제작 인계용 보조 기준이다. 새로운 스킬·장비·수치를 추가하지 않는다. 상세 수치와 예외는 각 기준 문서가 우선한다.

부품과 함선
기준19: 초기 구조는 핵심 선체를 루트로 하는 단일 부모 트리.
기준19/65: 부모 골조가 끊기면 하위 모듈이 한 묶음으로 분리된다. 함포 자체 파괴로 옆 엔진이 떨어지지 않는다.
기준19: 각 부품은 고유 ID, 내구도, 부모·소켓, 소유 출처를 유지한다. 소유권은 회수 완료 시 변경한다.
기준19/85/90: 회수·적재·제작·장착은 다른 상태다. 단순 회수로 자동 장착되지 않는다.
미정: 실제 소켓 치수, 물리 장력, 충돌 세부, LOD, 다중 부모 구조의 채택 여부.

양력과 전력
기준19: 총중량은 선체·부품·화물·구조 인원을 포함한다. 유효 양력은 작동 부양 장치의 출력 합이다.
초기값19: 기낭 내구도50% 이상 정상 출력, 미만 선형 감소. 다른 부품의 출력 규칙으로 자동 확장하지 않는다.
초기값19: 일반 침하 유예7초, 심각한 사고 직후 최소3초 대응. 일시정지에서는 유예도 멈춘다.
기준19: 전력 과부하는 지원 장비 우선순위로 처리한다. 조타 입력 반전은 없다.
예시50: 기본 함선 W50/L65, 발전14/소비10. 다른 배에 고정 복사하지 않고 실제 부품 합으로 계산한다.
미정: 실제 이동속도·선회·중심 안정화·접근성별 유예시간.

무기와 사격
기준21/72: 기관총·함포·박격포·작살포·사슬탄·화염방사기의 역할을 구분한다.
기준72: 포각·거리·장전·가림 조건을 만족해야 발사한다. 자기 선체를 통과해 쏘지 않는다.
기준49: 일제 사격은 준비된 무기만 발사하며 무료 추가탄이나 장전 초기화를 만들지 않는다.
기준18: 기본 탄환에 매 발 구매를 강제하지 않는다. 연료는 별도 자원이다.
미정: 실제 명중률·초당 피해 비교 가정·장비 호환성·포각 수치·무기별 최종 밸런스.

스킬과 소모품
기준49: 3계열 각7노드, 총21노드. 출항 레벨1~9, 총8포인트. 일반1점·궁극2점, 주력5+보조3 구성이 기본안.
기준49: 일반 액티브2개Q/E, 궁극기1개R. 궁극 해금은 계열 전문화·레벨6·2점·다른 궁극 미습득 조건.
기준37: 소모품은1/2 두 슬롯, 슬롯당 최대3개 초기안. 스킬 슬롯에 섞지 않는다.
기준95/111: 실제 바인딩을 바꾸면 HUD 표기도 갱신한다. 생성 아이콘은 실제 선택 노드를 대신하지 않는다.
미정: 출항 성장 속도, 초기화 피로, 실제 스킬 효과 밸런스, 입력 전환 옵션의 세부.

수리와 경제
기준18: 스크랩S·연료F·봉인 천C를 구분한다. 금화 화폐를 추가하지 않는다.
초기값18/49: 항구 수리0.25S/실제 복구 내구도, 전투 수리0.5S, 다중 수리0.4S. 각 기능의 조건과 대상 수는 상세 문서를 따른다.
기준18/66/106: 견적은 확정 전 미지불. 이미 복구한 손상을 중복 청구하지 않는다. 연료 소비를 스크랩과 같은 단위로 빼지 않는다.
초기값18: 매입 제작가1.5배, 매각0.3배, 분해35% 반환. 정수 반올림 정책은 미정.
기준19/49: 자기 부품 재회수에 새 드롭·감별·현장 개조 보너스를 반복 지급하지 않는다.
미정: 실제 수익 분포, 초행 수리 부담, 연료 보급량, 필수 복구 구제 경로의 최종 수치.

기억과 이야기
기준39/107: 프롤로그·4막·최종 항해. 첫 들숨은 수백 년 전, 선장 개인 사건은12년 전, 현재25세.
기준70: 물리 상태·기억 여부·조사/봉인 상태는 다른 축이다. 기억 부품은 무조건 상위 성능 등급이 아니다.
기준11/56: 이점과 대가를 공개하고, 반환·보관·봉인을 별도로 선택한다. 필수 단서에 비용·무작위 드롭 잠금 없음.
기준15/94/98: 핵심3결말은 개인 임무 완료율로 잠기지 않는다. 동료의 사적 결정은 본인의 의사와 연결한다.
미정: 일부 조연 이름, 정확한 최종 대사, 모든 개인 후일담의 제작 분량.

저장·정산·복구
기준45: 안전 경계 스냅샷 우선. 모든 물리 프레임을 정확히 복원한다는 약속은 하지 않는다.
기준66: 미션 정산 ID로 한 번만 지급. 확정 회수품과 미지불 수리 견적을 구분한다.
기준73/80: 선택 철수는 확정 성과 보존·미완료 보상 미지급. 패배는 체크포인트 복원.
기준10/80: 첫 보스 마지막 구조 실패는 구조 단계부터 재시도한다.
기준80: 저장 오류는 실제 기능 안내로 표시한다. 저주나 가짜 공포 UI로 숨기지 않는다.
미정: 엔진별 저장 형식, 슬롯 수, 충돌 복구 구현, 실제 파일 장애 테스트.

검증의 순서
1. 규칙 구현: 부품 분리·소유권·예산·정산이 일관되는지 확인한다.
2. 사용자 이해: 초행자가 원인과 복구 행동을 설명하는지 관찰한다.
3. 재미와 부담: 조작·회수·선택·반복의 피로를 확인한다.
4. 성능과 표시: 해상도·입력·접근성·저장 장애를 실제 환경에서 검사한다.
현재 파일 검사와 산술 확인만 수행한 항목을 이 단계의 통과로 표현하지 않는다.
