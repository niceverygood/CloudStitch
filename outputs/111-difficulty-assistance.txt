111. 난이도와 항해 보조 설정
상태:16번 접근성·19번 위험·40번 테스트·45번 저장·57번 도움·80번 복구·91번 예고 계승. 아래 설정은 후보이며 실제 배율과 프리셋 이름은 플레이테스트 후 확정한다.

핵심 규칙은 유지한다
골조를 끊으면 하위 묶음이 분리되고, 함포 자체를 부수면 함포만 멈춘다. 회수·장착·소유권·정산·세 결말 접근은 난이도에 따라 달라지지 않는다. 낮은 난이도에서 이야기를 생략하거나 선택을 대신 확정하지 않는다. 높은 난이도에서도 예고를 숨기거나 입력을 뒤집는 방식으로 어렵게 만들지 않는다.

난이도 프리셋 후보
여유로운 항해: 공격 사이 판단 시간을 늘리고 큰 공격 동시 수를 줄이는 방향. 적은 같은 장치·예고·회복 동작을 사용한다. 실수 후 복구 여유를 늘리되 무한 무료 수리·자동 승리는 기본으로 넣지 않는다.
표준 항해:19·25·49번 초기 규칙을 시작점으로 한다. 아직 정상 난이도 배율이 검증된 상태는 아니다.
거친 항해: 더 능숙한 적 위치 선택·보호 부품 조합·제한된 회복 시간을 후보로 검토한다. 적이 구름 속 현재 위치를 투시하거나 예고 뒤 사거리를 무근거로 늘리지 않는다. 적 체력만 크게 늘려 반복 사격을 강요하는 방향은 우선하지 않는다.
프리셋의 정확한 공격력·내구도·타이밍 배율은 미정. 화면에는 실제 적용 항목을 공개하고 숨은 수치 보정으로 위장하지 않는다.

접근성은 난이도와 별도
큰 글자·자막 배경·화자명·색과 모양 경고·섬광 감소·흔들림 감소·동작 감소·입력 전환·조준 보조를 개별 제공한다. 높은 난이도를 선택해도 자막과 시각 보조를 잠그지 않는다. 도움 설정 때문에 엔딩을 낮은 등급으로 표시하지 않는다. 실제 플랫폼 접근성 API 지원은 기술 검토 전 확정하지 않는다.

조준 보조
패드와 마우스의 차이를 고려해 약한 추적 보정 후보. 현재 가시 표적과 포각 안에서만 작동한다. 자기 선체·벽·구름을 투시해 목표를 고정하지 않는다. 무기 선택의 사거리·회전·장전 조건을 무시하지 않는다. 연결 골조를 선택하면 다른 부품으로 목표가 갑자기 바뀌지 않도록 잠금과 해제 피드백을 제공한다. 강도·전환 감도·대상 우선순위의 실제 수치는 미정이다.

시간과 위험 도움
양력 유예·구조 단계 제한 시간·퍼즐 관찰 시간은 개별 조정 후보다. 일반7초·심각 사고 최소3초는19번 초기값이며 옵션 변경 시 실제 적용 시간 표시. 일시정지 메뉴는 모든 난이도에서 해당 위험 타이머를 멈춘다. 첫 보스 마지막 구조 실패는 해당 단계 재시도 유지. 시간 보조가 기록 재현 도전 점수에 영향을 준다면 규칙을 시작 전에 공개하고 본편 서사 보상과 분리한다.

도움말과 재시도
반복 실패 후 원인에 맞는 선택 도움을 제안한다. 강제 자동 난이도 하락은 없다. 플레이어가 거절하면 같은 팝업을 매번 띄우지 않는다. 체크포인트·준비 다시 보기·항구 복귀의 상태 범위를80번 기준으로 설명한다. 새로운 설정을 적용할 안전 시점과 저장 상태를 표시한다. 전투 중 설정 메뉴를 읽는 동안 배가 더 빨리 침하하지 않는다.

설정 변경
새 게임 전과 일시정지·항구 설정에서 접근 가능. 변경 전후 값과 현재 적용 범위를 보여 준다. 입력 변경은 HUD의 Q/E/R·1/2 표기에도 동기화한다. 설정 초기화는 저장 진행을 삭제하지 않는다. 별도 슬롯별 난이도와 공통 접근성 설정의 범위는 엔진 구현 때 명확히 정한다.

스토리보드 6컷

검수
어려움과 정보 부족을 혼동하지 않는가? 도움 설정이 구조·부품 학습을 대신하는가? 조준 보조가 다른 부품으로 튀는가? 설정 변경 후 표시와 실제 값이 같은가? 실제 테스트 전이며 프리셋 밸런스가 검증되었다고 주장하지 않는다.
