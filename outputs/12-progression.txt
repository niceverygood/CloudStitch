12 스킬·연구·성장 화면 — 상세 기획 v0.1

성장 3층
출항 중 지휘 스킬: 임시 레벨 1~9, 총 8점. 일반 노드 1점, 궁극기 2점. 기동·포격·회수 각 계열 5점 완성, 주력 5+보조 3 기본. Q/E 일반 액티브 2개, R 궁극기 1개. 기존 21개 노드 기준 유지.
항구 연구: 영구적으로 제작법과 장착 기능을 해금. 자원과 회수한 설계도 사용. 같은 노드를 다시 반복 구매하지 않음. 연구는 출항 전 준비를 넓히고 기본 피해를 무한 누적하지 않음.
실물 장비: 현재 배에 장착한 부품과 강화 단계. 파괴·판매·분해 가능. 기술 해금과 실제 장착을 혼동하지 않도록 별도 탭.

스킬 화면
세로 계열 3개. 기초→액티브 두 선택지→전문화 두 선택지→궁극기 두 선택지. 선택하지 않은 형제 노드는 분명하게 잠김 이유 표시. 하단 현재 장착 Q/E/R과 남은 점수. 노드 선택 시 오른쪽 설명에 실제 장비와의 상호작용 및 대가. 테스트 영상은 짧은 반복 클립, 자동 재생 끄기 지원.
레벨업은 전투를 자동 중단시키지 않고 포인트 획득 알림만 표시. 싱글플레이에서 화면 열면 일시정지. 위험 중 스킬 설명 읽기 강요하지 않음. 안전 정박 지점에서 이번 출항 스킬 무료 재배치, 전투 중에는 재배치 제한. 같은 임무에서 무제한 궁극기 재충전을 막기 위해 재배치 후 궁극기 남은 대기시간 유지.

연구 화면
부품별 줄: 기본 설계→장착 안정화→개량 제작→특수 파생. 예: 함포 연구는 반동 장치·탄약 호환·중형 거치대 해금. '즉시 연구' 전에 소비 자원과 제작 가능 목록을 요약. 연구 취소는 확정 전 가능. 잠금 조건은 필요한 실제 부품/임무로 명시. 핵심 주임무는 한 연구 계열만 강제하지 않음.

강화 규칙
무기 4단계 시각 성장과 연동. 단계 상승마다 피해뿐 아니라 무게·출력·크기·장착 제한 변화. 장비 상세에 강화 후 미리보기와 현재 함선에 미치는 영향. 단계 4를 억지로 달기보다 단계 2를 여러 개 달 수도 있어야 함. 확률 실패 강화와 영구 파괴는 기본안에서 제외.

6컷 스토리보드
1 전투 후 레벨업 포인트 알림. 2 기동 노드 선택과 긴급 가속 클립. 3 현재 무장과 상성이 좋은 포격 전문화 안내. 4 항구 연구에서 반동 장치 해금. 5 실제 함포 2→3단계 외형·무게 비교. 6 스킬+장비 요약 후 다음 출항.
무드보드: 실제 메뉴 위주, 3계열 연결선과 선택/잠금 상태. 스킬과 연구를 한 트리에 섞지 않고 두 화면으로 비교. UI 문구는 짧고 큼.
