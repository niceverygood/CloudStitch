# Cloudstitch · 종항 항구 순환 예시 v1

`index.html`을 로컬 브라우저에서 엽니다. 기존 종항 미리보기 그림은 이 저장소의 `outputs/world-assets/`에서 불러오며, 인터넷 요청이나 npm 의존성이 없습니다. 저장은 브라우저의 현재 주소에 속한 로컬 저장소를 사용합니다. 파일 주소의 저장 허용은 브라우저 설정에 따라 다릅니다.

1. `저장 후 예시 출항`을 누릅니다.
2. `예시 임무 완료 · 귀환` 또는 `예시 선택 철수`로 독립 결과를 전달합니다.
3. 회수품을 선내 화물로 확인하고 `선내 회수품 모두 보관`으로 항구 창고에 내립니다.
4. 엔진과 빈 E2 위치를 골라 장착 전후 중량·양력·발전/소비와 거부 이유를 비교하고 장착합니다.
5. 미지불 수리 견적을 확인한 뒤 수리를 확정합니다. 실제 소비는 별도 영수증으로 남습니다.
6. 안전 저장 후 재출항합니다. 마지막 저장 불러오기는 미저장 작업을 버리기 전에 확인합니다.

회수품은 자동 장착·판매되지 않습니다. 창고 부품은 무게나 출력을 배에 더하지 않습니다. 선내 화물은 무게에만 더합니다. 항해 ID/정산 ID로 보상을 한 번만 지급하며 선택 철수에는 미완료 계약금을 지급하지 않습니다.

저장 실패 예시를 켜면 다음 쓰기만 실패시킵니다. 현재 세션을 유지하고 마지막 정상 저장을 보존합니다. 손상 저장이나 미지원 버전을 자동 초기화하지 않으며, 정상 백업 복구는 명시적인 버튼을 누를 때만 실행합니다. 정상 백업 최대 3개와 손상 원문 보관 기능이 있습니다. 저장 사본 다운로드는 원문 보존용이며, 이 화면에 파일 가져오기 기능은 없습니다.

이 화면은 **독립 예시 데이터로 구현한 항구·개조·정산·저장 시제품**입니다. 출항/귀환 버튼은 전장 이동·전투를 실행하지 않습니다. 천 시장은 기존 자산 카탈로그의 접점만 연결하며 매매·제작·봉인은 미구현입니다. 실제 게임의 재미·균형·엔진 성능 검증 결과가 아닙니다.

재현은 저장소 루트에서 실행합니다.

```sh
node tools/harbor/build.mjs
node --test tools/harbor/core.test.mjs tools/shipyard/shipyard.test.mjs tools/save/save.test.mjs
node tools/harbor/verify.mjs
```

검사 범위는 `verification.json`, 코드/통합 계약과 해시는 `tools/harbor/HANDOFF.md` 및 `file-manifest.json`을 확인하세요.
