메뉴 지도
일시정지 허브 → 함선 / 화물 / 선장 기술 / 항해 기록 / 동료 / 설정. 지도는 출항 중 항로 정보만, 항구에서는 새 항로 선택. 전투 중 전체 메뉴를 열면 싱글플레이 일시정지. 실제 제작 전 단축키·패드 탐색 통일 필요.

화물 인벤토리
좌측 목록, 중앙 선택 부품, 우측 성능·기억·출처. 상단 유형 필터와 검색, 하단 총중량·가용양력·항구 창고 전송. 정렬은 유형/무게/획득순/손상/기억. 즐겨찾기와 잠금 표시로 실수 분해 방지.
버튼: 장착, 수리, 봉인 상태 확인, 분해, 판매(항구). 현재 할 수 없는 버튼은 이유 표시. 대량 분해는 일반 고철 후보만 기본 선택, 기억 장비·즐겨찾기는 제외. 확정 전에 얻는 자원과 사라지는 물건 요약.
장비 비교는 현재 장착부품을 사용자가 지정. 여러 포탑이 있으면 자동으로 가장 약한 것을 교체하지 않음. 새 부품이 호환되는 빈 소켓이 없으면 해당 소켓 규격 안내. 화물 공간을 다른 메뉴에서 숨기지 않음.

항해 기록
탭: 주임무 / 선택 계약 / 기억 / 인물·세력 / 튜토리얼 / 완료 항해. 현재 추적 주목표1개와 선택목표1개. 과거 대사 재열람과 발견 출처 링크. 미확인 항목은 '미발견' 정도만, 후반 이름·초상 스포일러 노출 금지.
임무 카드: 목적, 현재 단계, 알려진 조건, 확정 보상, 선택 결과. '지금 출항하면 이 대화는 보류' 같은 실제 영향 안내. 임무 완료 뒤 지급된 설계도·자원과 항구 변화를 함께 기록. 기억 도감은 물건의 고유ID와 분리되어 반환해도 읽을 수 있음.

대화 화면
장면과 인물 유지, 하단 자막 박스, 화자 이름, 대화 기록 버튼. 선택지는 기본 최대3개, 의미가 비슷하면 통합. 말풍선의 짧은 요약과 실제 대사가 다른 어조로 튀지 않게 작성. 질문은 조사 아이콘, 행동 확정은 별도 아이콘. 색만으로 관계 영향 암시하지 않음.
보이스 자동 재생·속도·자막 크기·스킵·이전 문장 확인. 중요한 선택을 단순 대사 넘기기 버튼과 같은 누름으로 확정하지 않음. 장비 화면을 열어 대화 조건 확인 후 돌아와도 문맥 보존.
시간제 선택은 일반 대화에서 제외, 긴박한 구조 장면만 제한적으로. 시간제 끄면 같은 선택 콘텐츠 제공. 주인공 음성 성별·인칭은 커스터마이즈 범위 확정 후 통일.

동료 메뉴
현재 역할·지원 효과·개인 임무·약속 기록·선실 기념품. 단일 호감 수치를 숨긴 채 사실상 선물 반복 시스템으로 만들지 않음. 동료가 무엇을 알고 있는지 기록. 다른 임무 순서에서도 말하지 않은 비밀을 먼저 아는 대사 방지.

알림 원칙
새 고철 하나마다 팝업 없음. 묶음 획득, 새 설계도·기억만 강조. 위험 경고가 우선. 새 항목 표시는 읽거나 일괄 지우기 가능. 메뉴에서 알림을 없애려고 모든 칸을 클릭할 필요 없음.
