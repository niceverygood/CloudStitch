Cloudstitch · 클라우드스티치 맥북 작업 시작
이관 기준: 2026-10-18 / niceverygood/CloudStitch / main

1. 저장소와 실제 에셋 받기
Git과 Git LFS가 설치된 맥북 터미널에서 원하는 작업 폴더로 이동한 뒤 실행한다.

git lfs install
git clone https://github.com/niceverygood/CloudStitch.git
cd CloudStitch
git lfs pull
git status
python3 tools/verify-assets.py

검사 기준은 PNG505개 + GLB181개 = 686개, 총1,393,678,141바이트다. 원본·수정본·합성 장면을 모두 포함한 실제 파일 수이며 독립 게임 오브젝트 종류 수와 다르다. docs/asset-inventory.json에 경로·크기·SHA-256이 있다. 큰 월드 index.html/scenes.html도 Git LFS로 받는다.

이미 clone한 저장소가 있으면 로컬 수정을 먼저 보존하고 git pull --ff-only 후 git lfs pull을 실행한다. 기존 폴더를 초기화하지 않는다. HTML이 짧은 LFS 포인터 텍스트로 보이거나 PNG/GLB가 열리지 않으면 git lfs pull을 완료한다. 저장소가 비공개일 때는 GitHub 접근 권한이 있는 계정으로 인증한다.

2. 바로 보기
HTML 열람에는 Node·Python 패키지·게임 엔진이 필요 없다.

open outputs/world-assets/gallery-overview.html
open outputs/world-assets/gallery.html
open outputs/world-assets/scenes.html
open outputs/selected-airship-toon3d/viewer-v2.html
open outputs/cloudstitch-title-screen/index.html

파일을 옮기거나 이름을 바꾸지 않고 저장소의 상대 경로를 유지한다. ZIP은 같은 에셋을 중복 포장한 파일이라 제외했으며 개별 원본·수정본·프롬프트·명세·검사 요약·뷰어·재현 소스가 저장소에 들어 있다. work/node_modules/Meshy 원시 응답/로컬 인증은 가져오지 않는다.

3. 소스 수정과 QA가 필요할 때만
Node.js20 이상(22 이상 권장)과 npm, Python3를 준비한다. 저장소 루트에서:

npm ci
npm run setup:browser
npm run build:world
npm run verify:world
npm run verify:world-scenes
npm run verify:world-gallery

공식 glTF 검사·로컬 월드 재생성에는 추가 검증 모듈이 필요하다:
npm install --prefix work/vfx-validation --no-save --package-lock=false gltf-validator@2.0.0-dev.3.10
node tools/qa/world-gltf.cjs
node tools/qa/gltf-vfx.cjs work/vfx-validation/node_modules/gltf-validator

이미지 메타 검사·최종화·패키징 Python 도구를 쓸 때만 Pillow를 설치한다. macOS 시스템 Python에 직접 설치하지 않고 프로젝트 work 아래 가상환경을 사용한다:
python3 -m venv work/python-venv
work/python-venv/bin/python -m pip install Pillow

전체 QA 원본 work/verification은 Git 제외다. outputs/*/verification.json 등에 최종 요약이 보존되어 있다. 최종화를 다시 하려면 현재 파일로 아래 원본 QA를 먼저 만든다:
node tools/qa/world-workbench.cjs outputs/world-assets/index.html work/verification/world-workbench outputs/world-assets/catalog.json all 96
node tools/qa/world-workbench.cjs outputs/world-assets/scenes.html work/verification/world-scenes outputs/world-assets/scene-catalog.json all 7
node tools/qa/world-gallery.cjs
work/python-venv/bin/python tools/world-assets/finalize.py

기존 에셋 열람·뷰어 빌드에 Meshy 로그인은 필요 없다. 새 유료 생성을 요청할 때만 맥북에서 별도 인증한다. 인증 키·세션 상태를 Git에 넣지 않는다. npm run generate:world는 로컬 형상을 다시 쓰는 도구이며 열람이나 이관 확인에 필요 없다. 현재 generator는 로컬 state.json이 없으면 공개 manifest의 작업ID·operationID·소비크레딧 세 필드만 보존한다.

4. 맥북 Codex에서 이어가기
clone한 CloudStitch 폴더를 Codex 프로젝트로 연다. docs/CONTINUE_PROMPT.md 또는 outputs/handoff/CONTINUE_PROMPT.md의 프롬프트를 붙여넣는다.

짧게 시작하려면:
"Cloudstitch 작업을 이어가줘. AGENTS.md, README.md, docs/HANDOFF.md, docs/CONTINUE_PROMPT.md를 먼저 읽고 git status와 실제 파일을 확인해줘. 2026-10-18 이관 자료의686개PNG/GLB와 무기6종·효과48종/공격시연6종·월드96자산/7장면을 확인해줘. Windows 절대경로나 이전 채팅 캐시를 전제로 삼지 말고 기존 원본을 보존해줘. 게임 엔진과 성능 예산은 아직 미정이고 실행 가능한 전투 게임은 없어. 새 유료 생성이나 과거 자동화를 시작하지 말고, 현재 상태와 다음 작은 구현 단계를 정리해줘."

정식 제목은 Cloudstitch / 클라우드스티치다. 현재 작업은 기획·아트·정적/애니메이션 GLB·오프라인 뷰어이며 게임 전투·충돌·navmesh·소켓·저장 구현과 구분한다. OutlineEffect.autoClear=true를 유지한다.
