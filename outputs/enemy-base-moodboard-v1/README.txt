Cloudstitch · 적군 기지 무드보드 v1
제작일: 2026-10-18 (Asia/Seoul)

목적
사용자의 적군 기지 요청 중, 먼저 무드보드를 제작하는 범위다.
손그림의 온기와 낡은 기계가 쌓인 공중 건축을 바탕으로 2D 느낌의 3D 아트 방향을 제안한다.
기존 마지막 숨 교단의 봉쇄 전초기지를 시각적 후보로 삼았다. 새 정사나 확정된 기지 이름은 아니다.

아트 방향
층층이 증축된 비대칭 실루엣, 청록 지붕, 꿀빛 목재, 황동 배관, 크림색 봉인천,
먹색 보일러와 높은 종탑, 경계 포대, 계류장. 두세 단계 명암과 무광 붓 질감으로 입체를 표현한다.
참고 작품의 향수와 기계 판타지 감성을 바탕으로 Cloudstitch 고유 구조를 제안한다.

파일
moodboard.png: 생성된 무드보드 원본. 수정이나 리사이즈 없이 보존한다.
prompt.txt: 실제 내장 image_gen 도구에 전달한 전체 프롬프트.
manifest.json: 실제 생성 파일의 크기·해시·검사·범위 기록.

제작 방식과 범위
내장 image_gen 사용. API 키나 Meshy 유료 모델 생성을 사용하지 않았다.
참조 그림은 읽어 확인했고, 색·재료·세력 특징을 텍스트 프롬프트로 전달했다.
이 파일은 정지 콘셉트 이미지다. 3D 모델·GLB·실시간 셰이더·기지 전투 기능은 아직 제작하지 않았다.
그림 속 장비 수, 배치, 치수와 표식은 시스템 사양이 아니다. 구현·게임 성능·밸런스 검증 결과가 아니다.
기존 원화·모델·로컬 작업을 덮어쓰지 않았고 Git commit/push·외부 배포를 하지 않았다.
