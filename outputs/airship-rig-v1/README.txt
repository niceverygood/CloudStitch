Cloudstitch · 귀환호 — 리깅·애니메이션 v1
제작일: 2026-10-18

viewer.html을 브라우저로 열면 서버나 인터넷 없이 움직이는 비행선을 확인할 수 있습니다.
airship-rigged.glb에는 실제 스킨·뼈대·애니메이션이 들어 있습니다. 뷰어에서만 움직이는 정지 모델이 아닙니다.
기존 selected-airship-toon3d의 원본 GLB·원화·뷰어는 보존했습니다.

제작 내용
9개 제어 뼈대: RigRoot, HullMotion, EnvelopeFlex, EngineVibration, PropellerSpin, TurretYaw, GunRecoil, WinchDrum, HookSwing.
8개 원본 부품군: 선체/선장실, 기낭/밴드, 엔진, 프로펠러, 포탑, 포신, 윈치 드럼, 갈고리/사슬.
3가닥 케이블을 추가하고 위쪽은 선체, 아래쪽은 갈고리를 따르게 스키닝했습니다.
원본 11,026삼각형의 위치·UV를 보존하고 케이블 960삼각형을 더해 총 11,986삼각형입니다.
원본 2048×2048 컬러 텍스처를 사용하며 케이블용 무광 재질이 추가되었습니다.

내장 동작 7종
FloatIdle: 느린 부유와 서로 다른 위상의 기울기, 뒤늦게 따라오는 갈고리.
Cruise: 작은 상하 진동과 가벼운 전진 자세, 빠른 프로펠러.
BankTurn: 방향 변화와 기울기를 시간차로 연결한 좌우 선회.
GustRecovery: 돌풍 충격 이후 흔들림이 줄어들며 자세를 되찾는 연출.
TurretScan: 끝에서 부드럽게 감속하는 포탑 조준.
WinchCycle: 드럼 회전, 갈고리 내림·대기·회수와 케이블 연결.
FireBurst: 3발의 빠른 포신 후퇴, 느린 복귀와 지연되는 선체 반동.

조작
드래그 회전 / 휠 확대 / 오른쪽 드래그 이동.
동작 선택 / 재생·일시정지 / 속도 조절 / 시간 이동 / 뼈대 표시.
손그림·셀 명암·원본 재질과 윤곽선 두께 비교. 모션 감소 환경에서는 일시정지 상태로 시작합니다.
GLB 다운로드 버튼은 현재 리깅 자산을 저장합니다.

다른 제작 도구에서 사용
GLB를 가져와 실제 skeleton과 7개 clip을 확인합니다. 단단한 기계 부품은 가중치 1로 제어하고, 기낭·지지 로프·케이블만 제한적으로 혼합합니다.
원본 좌표를 유지했습니다: +Y 상방, -X 전방. 실제 미터 치수와 게임 엔진은 아직 미정입니다.
Socket_W1/E1/L1/S1, Muzzle, HookGrip은 위치 검토용 임시 장착 노드입니다. 양력·전력·장착 규격을 확정한 데이터가 아닙니다.
모델 이동/항로는 게임 코드가 담당하고 내장 클립은 제자리 동작입니다.
뷰어의 손그림·셀 명암·윤곽선은 런타임 표시 기능입니다. GLB의 기본 재질만 가져오면 동일한 화면이 자동 재현되지는 않습니다.

검증과 제한
manifest.json에 모델 해시·부품·피벗·동작 정보를 기록합니다. verification.json과 gltf-validation.json은 최종 산출물에 대응하는 검사 기록입니다.
이 작업은 에셋과 동작 시연입니다. 비행 물리·전투·절단·회수 게임 로직은 구현하지 않았습니다.
원본 생성 모델의 후면 추정·닫히지 않은 내부·자동 생성 토폴로지 특성은 남아 있습니다. 부품 분리는 연결 섬 단위이며 전체 리토폴로지/새 텍스처 제작이 아닙니다.
충돌체·LOD·특정 엔진 임포트·실제 모바일 기기 성능은 후속 검증입니다.

재현
저장소 루트에서 npm ci 후 npm run build:rig, npm run verify:rig, npm run verify:gltf를 실행합니다.
