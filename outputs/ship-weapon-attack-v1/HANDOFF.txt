Cloudstitch · 장착 무기 공격 비교 v1

실행: outputs/ship-weapon-attack-v1/index.html을 브라우저에서 열고 ‘발사’를 누른다.
기동 연발 쇠뇌 / 포격 3로켓 / 인양 작살의 기본·강화를 동일 모델·카메라·6초 시간축에서 비교한다.
좌우는 시각만 동시 재생한다. 음향은 선택한 한쪽만 재생하며 최초 사용자 클릭이 필요하다.
마우스로 회전·확대, 타임라인으로 시간 이동, 세 표시 모드·윤곽선·효과·움직임 줄이기를 사용할 수 있다.
WAV는 현재 계열·음향 버전의 실제 6초 스테레오 믹스, 기록은 공통 이벤트 시각 JSON이다.

읽기 입력: ship-weapon-harmony-v1 final r2 실제 GLB3, audio-ship-weapon-attack-v1 전용 이벤트 WAV24.
빌드 시 입력 SHA를 대조하고 HTML에 모두 내장한다. 외부 요청과 fallback은 없다.
원본 GLB/텍스처·WAV 보존. GLB3에는 원래 없는 애니메이션을 추가 저장하지 않는다.
실제 기구·발사체 그룹을 런타임에서 움직이며 개별 투사체의 월드 경계에서 출발점·표적면을 계산한다.
장착대·받침·선체 반동, 쇠뇌 당김, 로켓 순차 배기, 작살 드럼·케이블 장력을 구현한다.
기본·강화의 발사/비행/명중 시각과 표적은 같고 연출·반동 세기·전용 음향만 비교한다.

범위: 독립 아트 시연. 게임의 sim·피해량·충돌 범위·저장·장비 규칙은 변경하지 않았다.
표적은 고정 목재·철제 테스트 모듈이며 실제 적 함선의 파괴/AI 구현이 아니다.
표적면 교차는 고정면을 기준으로 계산하며 명중 뒤 기울임은 시각 반응이다.
강화 40ms 접촉 구간은 시각 기구/표적 반응만 잠시 붙잡으며 시간축과 오디오는 진행한다.
음향은 기존 프로젝트 파형 조각과 로컬 절차적 DSP 시제품이다. 출처/합성/음량 수치는 음향 담당 cue-map에 있다.
기술 검사와 사람의 미술·청감 승인은 구별한다. 사용자 청취 승인은 아직 받지 않았다.

재빌드: 기존 three/esbuild 경로가 NODE_PATH에 설정된 환경에서 node tools/ship-weapon-attack-v1/build.cjs
검수: 중앙 heavy START 승인 후 node tools/ship-weapon-attack-v1/verify.cjs --slot-start
검사 결과는 qa-r1/verification.json, 캡처 및 실제 OfflineAudioContext 믹스6에 기록한다.
검수 및 최종판 기록 (2026-10-19)
- qa-r1: GLTF 부모 노드를 Group으로만 제한한 오류. Object3D의 이름·자식 구조로 수정.
- qa-r2/r3: 정지 캔버스 PNG 엄격 동일성 실패. 실패 기록과 초기 캡처 보존.
- qa-diagnostic: 노드/카메라/재질 opacity/자원 고정. 픽셀 차이가 투명 효과 경계에 한정됨을 확인.
- qa-r4: MSAA off 분리 진단에서 45검사 통과. 24큐 실제 예약/취소·6믹스·다운로드·모바일 포함. 최종 AA 설정은 아니다.
- qa-final: 원래 MSAA true 복원. 10검사 통과. 정지 0→240 214pixel/max20, 0→480 172/max20, 240→480 159/max12. 노드·카메라·opacity·자원은 비트 단위 동일. 엄격 픽셀 동일성은 false이며 잔상 누적 성장 없음으로 관찰. 정확 동일 PASS로 표시하지 않음.
- qa-art-final: 사용자 요구에 맞춘 effects.js 보완 최종판, 28검사 통과. 실제 GLB3/같은 시간·발사점·전탄 명중/세 표시 모드/모바일/효과 120회 동일 적용에 누적변환 없음. 최종 캡처9+mobile1.
- audio/events/rig/template은 qa-r4와 동일 SHA로 최종판에 연결. qa-final에서 원AA 복원 뒤 실제 음향 예약/취소도 확인. 효과만 바뀐 뒤 음향 검사를 반복 합산하지 않았다.
- 실제 믹스 최대 peak .440515, clip0. 기본/강화 RMS 차이 약 쇠뇌 -.26dB/로켓 +.28dB/작살 -.03dB. 음량을 올린 비교가 아니다.
- 전용 source 24cue와 최종 믹스6은 별도이다. 브라우저는 긴 전체믹스를 cue로 재생하지 않는다.
- 최종 영향 제한: 시각 명중층은 목판 뒤 가림을 피하도록 접촉점에서 -X .12만큼 표시 위치를 옮기고, 주 도형2개/불꽃 혀만 만화적 overlay로 읽힌다. 실제 투사체 표적면·시각 이벤트 시각은 불변.
- 40ms 구간은 기구 반응 감쇠·표적 접촉 포즈 유지에 한정된 짧은 시각 연출이다. 전역 시계나 오디오를 정지하는 엔진 hitstop은 아니다.
- 오디오 예약은 WebAudio 시간, 시각은 동일 이벤트 표를 브라우저 프레임에 표시한다. 프레임률/출력장치 지연까지 sample 단위 동기화를 보증하지 않는다.
- 최종 3impact PNG를 직접 읽음: 로켓은 표적 규모의 굽은 산호/황금 불꽃과 크림 압력층, 쇠뇌는 긴 관통 쐐기/목재 쪼개짐, 작살은 황동 쐐기/청록 금속 파편·케이블이 구별되고 선체가 계속 읽힘. 최종 인간 미술·직접 청감 승인은 미확정.
- 기존 GLB3+음향24 총27 source는 모든 실행 뒤 SHA가 보존됐다. 브라우저·서버 잔존0, 새 GLB/유료 호출/게임 sim 변경0.
