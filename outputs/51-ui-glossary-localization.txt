51 용어·UI 문구·현지화 기준

핵심 용어
검은 부력: 작품명. Black Buoyancy는 영문 가제이며 정식 상표·출시명 검토 전.
귀환호: 어머니가 남긴 배의 원래 이름. 플레이어가 항구에서 변경 가능.
접합선: 다른 배의 부품과 기억을 흡수하는 특수 선박 유형. 배명과 구별.
선체: 핵심 구조 또는 넓은 의미의 배 몸체. UI에서 패배 원인은 '핵심 선체 파괴'.
부양낭: 천으로 된 부력 장치. 풍선·기구·부력선으로 제각각 표시하지 않음.
양력: 비행을 지탱하는 총 성능, 무게와 비교하는 수치. 이야기의 '부력'과 게임 통계의 '양력'은 구별해 사용.
동력: 현재 작동 상태를 설명하는 총칭. 세부 비교 UI는 추진 성능과 전력 예산으로 나눔. 숫자 하나에 엔진 속도와 장비 전력을 섞지 않음.
연결 골조: 모듈을 선체에 붙이는 구조 부품. 케이블은 견인선, 장식 로프는 구조 판정이 아님.
회수: 분리 잔해를 가져오는 기본 행동. 인양: 무거운 물건을 견인·들어 올리는 행위. 노획: 적에게서 얻은 부품의 출처.
기억 장비: 이름·기억·이점·대가를 가진 고유 모듈. 저주와 희귀도를 동일시하지 않음.
봉인: 고유 이점과 대가를 함께 잠그는 행동. 정화는 기억 임무로 상태가 바뀌는 사건, 단순 상점 구매와 구별.
반환: 기억의 주인에게 물건과 이름을 돌려주는 행위. 고철 분해와 다른 버튼·아이콘.
출항 기술: 이번 항해의 임시 선장 스킬. 연구: 항구에서 영구 해금하는 제작법. 강화: 실제 부품 단계 상승.

주요 버튼
새 항해 / 계속하기 / 항해 기록 / 설정 / 종료.
장착 / 보관 / 수리 / 강화 / 분해 / 판매 / 봉인 / 이름 돌려주기.
출항 준비 / 출항 / 항구로 복귀 / 최근 지점에서 다시 시도.
확인 / 취소보다 행동이 분명한 문구를 우선: '장갑 2개 분해', '이 항해 덮어쓰기'. 위험한 확인은 취소에 기본 포커스.

상태 문구
양력 부족: '무게가 양력을 초과합니다. 화물을 내리거나 부양 장치를 보강하세요.'
전력 부족: '장비 전력이 부족합니다. 지원 장치 우선순위를 조정하세요.'
소켓 불일치: '이 거치대에는 중형 함포를 장착할 수 없습니다.'
사각: '현재 방향은 선체에 가려집니다.'
고철 부족: '고철 12개가 더 필요합니다.' 숫자와 자원명은 데이터로 삽입.
회수 불가: '견인 무게를 초과합니다.' 또는 '장애물이 케이블을 막고 있습니다.'
저장 재개: '최근 안전 지점에서 항해를 재개합니다.'
기억 반환: '부품은 떠나지만 발견한 기록은 남습니다.'

문장 톤
UI는 간단하고 정확하게, 이야기 대사는 인물별 말투. 시스템이 비꼬거나 플레이어를 비난하지 않음. 함선 손실 원인과 해결책을 함께 제시. 세계관 은유를 핵심 오류 메시지 대신 쓰지 않음.
마라: 짧고 실용적, 손상과 사람을 함께 봄. 오르: 무뚝뚝하지만 구체적 도구 비유. 에다: 관찰은 정확하고 의미는 조심스럽게, 아는 척하는 수수께끼만 반복하지 않음. 어머니: 개인적인 기억과 후회, 모방 목소리는 작은 사실의 어긋남.

표기·번역
가상의 원문 한국어 기준, 영문 번역은 다음 제작 단계. 스킬명·물건명은 고유 키로 관리. 숫자·단위·복수·호칭을 문장 중간 문자열 조각으로 조립하지 않음. 이름 삽입은 사용자 입력을 안전한 텍스트로 처리.
한국어 조사는 이름 뒤 형태를 고려하거나 '선장' 호칭으로 회피. 대사 자막은 화자 이름과 분리. 번역 길이 증가를 위한 여백, 줄바꿈·폰트 대체·글자크기 확대 검수.
스크린샷 자동 생성 문구는 정식 번역 자산으로 사용하지 않음. 이미지 속 오류는51문서와 각 기능 명세를 기준으로 대체.
