# Cloudstitch · 1막 최종보스 무드보드 v1

기준일: 2026-10-18 (Asia/Seoul)
상태: 정지 이미지 제작·파일 확인 완료, 사용자 미술 검토 대기.

사용자의 직접 요청인 ‘진짜 악당, 괴물처럼, 웅장하게’를 1막 정사 보스 **종을 삼킨 자 — 장례전함**에 적용했다.
범위는 이 폴더의 새 PNG 한 장과 제작/인계 기록뿐이다.

- `moodboard.png`: 1536×1024 PNG 생성 원본. 리사이즈·합성·후처리 없이 복사 보존.
- `prompt.txt`: 내장 image_gen에 전달한 전체 생성 프롬프트.
- `manifest.json`: 정사 근거, 아트 변경, 실제 파일 정보와 검사 한계.
- `READY-r1.json`: 이 폴더의 동결 파일 목록·크기·SHA256.

괴수의 얼굴처럼 읽히는 철갑 선수, 엄니 같은 충각, 거대한 종과 갈비뼈형 종실, 부푼 크림 기낭, 왕관형 연통을 사용했다.
먹청 판금·검붉은 하부·낡은 황동·청록 추진기를 따뜻한 종이 위 손그림 붓결과 입체적인 명암으로 표현했다.
주인공선과의 크기 대비, 종실·철갑·추진/인양 장치 세부 패널을 포함한다.
유기체 괴물로 설정을 바꾸지 않았으며 종·측면 포대·후방 추진기·윈치의 정사 역할을 유지했다.

실제 확인: 생성 이미지의 주 실루엣·종·괴수형 선수·크기 대비·세부 패널·한글 표제를 직접 확인했다.
PNG 시그니처·1536×1024 치수·3,460,638바이트·SHA256·생성 원본과 복사본 해시 일치, 기존 PNG Git LFS 규칙을 확인했다.
실제 3D 렌더나 게임 플레이 검사가 아니며 사람의 미술 승인은 별도다.

원본 보존: 기존 이미지·GLB·뷰어·공통 소스는 수정하지 않았다. 기존 악당 모델 소유 경계도 변경하지 않았다.
읽기 의존성과 전체 프롬프트는 manifest/prompt에 기록했다. 외부 이미지 입력 없이 새로 생성한 시각 제안이다.
브라우저·모델 exporter·중앙 QA 슬롯·Meshy·자동화·배포·commit/push는 사용하지 않았다.

통합 검토 범위: 이 PNG와 기록만 열어 이미지 파일·표제·보스 정체성·최신 아트 기준을 확인한다.
브라우저/GLB 하네스는 필요 없다. 포대 수·정확한 치수·장착 구조·피해/충돌·전투 성능은 확정하지 않는다.
