92. 시작 화면 움직임과 메뉴 진입 — 정박한 배가 숨 쉬는 시간
상태:01번 타이틀·39번 정사·45번 저장·51번 용어·79번 선장 생성 계승. 실제 애니메이션·영상·음원은 없다.

타이틀의 고정 구도
왼쪽 약35%의 어두운 여백은 로고와 메뉴, 오른쪽은 밤의 종항에 정박한 초기 귀환호. 로프·천·구름·작업등만 작게 움직인다. 중요한 메뉴 뒤를 밝은 구름이나 복잡한 리벳이 계속 지나가지 않는다. 진행도에 따른 배 외형 변형은 마지막 안전 저장의 현재 함선을 읽는 후보이며 최종 반전을 배경에 노출하지 않는다.

움직임 층
먼 구름 느린 이동, 기낭 천의 작고 자연스러운 팽창, 계류줄 미세 장력, 세 작업등 중 하나의 불규칙한 밝기 변화. 빛 변화는 강한 섬광이 아니라 낮은 범위이며 섬광 줄이기에서 일정하게 고정한다. 반복 노크·갑작스러운 얼굴·정체를 말하는 속삭임은 타이틀 루프에 넣지 않는다. 동작 줄이기에서는 구름과 로프 속도를 낮추거나 정지 배경으로 대체한다. 실제 루프 길이는 성능·아트 검토 후 정한다.

메뉴
계속하기/새 항해/항해 기록/설정/종료. 계속하기는 저장이 없으면 비활성 이유를 짧게 표시하고 기본 포커스를 새 항해로 둔다. 선택 강조는 크림 직사각 프레임과 작은 위치 표식이며 색만 바꾸지 않는다. 패드·키보드·마우스를 바꾸면 실제 입력 안내만 갱신하고 포커스를 잃지 않는다.

계속하기
저장 요약 카드: 최근 안전 지역·임무명·마지막 성공 저장·함선 실루엣. 확인되지 않은 정체·엔딩 스포일러는 넣지 않는다. 불러오기를 선택하면 조용한 짧은 전환 후 저장 경계에 복귀한다. 저장 오류는80번의 명확한 기능 안내로 표시하며 공포 연출로 위장하지 않는다.

새 항해
새 슬롯 선택→79번 선장 프리셋·이름→접근성·난이도→확인→오프닝. 기존 슬롯 덮어쓰기는 해당 슬롯·사라지는 진행을 보여 주고 별도 확인한다. 기본값 빠른 시작 가능. 첫 설정 화면에서 자막·큰 글자·흔들림·섬광 옵션에 바로 접근한다. 게임플레이가 시작되어야 접근성을 켤 수 있는 순서를 피한다.

오프닝과 조작 복귀
01번65초 내외6컷 구조를 유지하되 실제 편집 시간은 가설. 입항 표식·어머니 휘장·빈 식탁·닫힌 문·한 번의 노크·조작 복귀. 따뜻한 수프는39번의 기억 영향으로 해석하며 숨겨진 현재 승무원을 추가하지 않는다. 초반 목표는17번 프롤로그의 실제 단계와맞춰 사용한다.01번 오래된 감정사 도입 문구와17번 상세 조작 흐름이 충돌하면17번 상세와39번 정사를 우선한다.

건너뛰기
현재 영상만 건너뛰며 새 게임 전체를 즉시 끝내지 않는다. 도중 입력 한 번을 확인 오발로 처리하지 않도록 바인딩과입력 초기화. 스킵 뒤 현재 선장·배·목표가 같고 필수 문장의 짧은 일지 요약을 제공한다. 반복 플레이에서 건너뛰기 안내를 숨기지 않는다.
