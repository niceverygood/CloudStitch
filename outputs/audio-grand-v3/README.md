# Cloudstitch · 웅장·극적 사운드 v3

전체 효과음47종과 박격포 A·B 후보2종, 총49개를 더 낮고 두터운 재료음과 짙은 공간으로 다시 구성한 검수본입니다.

최초 생성된 소리에서 음고를 낮추고, 날카로운 고역을 정리한 뒤 원음에서 뽑은 모노 몸통층·따뜻한 압축과 포화·어두운 반사와 확산 잔향을 더했습니다. 함포·폭발·파손은 큰 압력과 여운을, 목재·황동·기계는 묵직한 재료감을, 경고·UI는 구별되는 윤곽과 단단한 조작감을 목표로 조정했습니다.

**이전 중저음 v2 WAV ↔ 웅장·극적 v3 WAV**를 비교합니다. ‘v2 → v3 비교’로 두 버전을 번갈아 듣고 검수 메모를 남길 수 있습니다. 기본 비교는 전체 파일의 RMS를 맞추며 peak.8 안에서 보정합니다. 어택과 여운·길이 차이는 그대로 남습니다.

- `original/`: 이전 v2 WAV49개,16,582,724B
- `enhanced/`: 새 v3 WAV49개,19,294,884B,44.1kHz stereo PCM16
- `catalog.json`: 원재료 출처, 이전 버전과 별도 처리원본의 SHA, 개별 pitch·몸통·다이내믹·공간 레시피

단발은 낮아진 음고와 추가 여운 때문에 길이가 달라집니다. 환경·기계 루프10종은 원래 길이를 유지합니다. 음성·음악·추가 총성·새 박자·새 정현파 레이어는 만들지 않았습니다. 실제 게임의 발사 주기나 피해·효과 종료 이벤트도 바꾸지 않았습니다.

실제 파일/fixture 검사646/646, 플레이어 모의검사43/43을 통과했습니다. 이는 유한 파형·개별 peak·pitch/길이/루프·모노·출처·원본 보존 등의 검사입니다. 웅장함과 음색 취향에 대한 사람의 청취 승인을 뜻하지 않습니다. 브라우저 최종 검사는 통합 담당의 별도 보고서에 기록합니다.

최종 검수 화면은 통합 담당이 선별 연결한 `http://127.0.0.1:8840/outputs/audio-grand-v3/`입니다. 이전 버전과 메모는 보존합니다. 기존 박격포 발사음 반려와 A·B 미선택 상태도 유지하며 새 v3도 청취 승인 전입니다. 추가 유료 생성·게임 적용은 하지 않았습니다.
