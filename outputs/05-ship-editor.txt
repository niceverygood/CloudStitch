05 함선 편집과 장비 메뉴
목표: 붙이면 강해지는 즐거움과 무게·양력·동력의 설계 선택을 함께 제공.
좌측 부품 목록 필터: 무기/방어/기동/회수/지원. 중앙 함선 3D 검사, 우측 선택 부품 성능과 기억. 하단 무게·양력·출력 및 출항 가능 여부. 위치 격자와 모듈 소켓 병용, 임의 교차 관통 금지.
편집 순서: 부품 선택 → 호환 소켓 강조 → 투명 미리보기 → 발사각·충돌·무게 변화 확인 → 확정. 취소·되돌리기 지원. 연결부 제거 시 떨어지는 전체 하위 모듈을 먼저 강조. 판매와 분해는 장착과 구별되는 확인.
전투 중 빠른 장착은 전투용 예비 소켓에만 가능, 전체 재배치는 안전 지역에서. 무장 방향 제한과 자신의 선체에 막히는 사각은 부채꼴로 표시.
무드보드 6장면: 편집 전체 UI / 함포 미리보기 / 연결 트리 / 불균형 양력 경고 / 기억을 가진 포탑 상세 / 출항 가능 검증 완료.
장비 비교: 기본 피해·사거리·장전·무게·전력·부가효과. DPS 하나로 모든 성능을 평가하지 않음. 동일 성능이라도 크기·발사각·기억 효과로 구별.
