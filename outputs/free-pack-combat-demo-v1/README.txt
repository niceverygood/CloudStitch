Cloudstitch · 무료 팩 함선 사격 시연

index.html을 브라우저로 열고 ‘소리와 함께 재생’을 누릅니다.
함포 한 발 / 기관총 2초 연사, 나란히 비교 / 신규 크게 보기,
포구 / 명중면 확대와 느린 재생을 선택할 수 있습니다.

적용: Brackeys VFX Bundle의 Thomas Iché 8x8 플립북 3종(CC0).
출처: https://brackeysgames.itch.io/brackeys-vfx-bundle
원본 보관: outputs/external-vfx-free-review-v1/.
무료 시각 에셋을 실제 함선/무기 장면의 발사와 명중 사건에 연결했습니다.
우측은 불꽃 폭발, 짧은 가산 섬광, 지연 연기의 연속 이미지입니다.
10배 이상 과감한 표현 목표를 위해 순간 섬광→팽창 화염→긴 연기를
분리하고 함포의 무게와 기관총의 짧은 리듬을 다르게 구성했습니다.
사람의 미술/청감 승인 및 해당 체감 목표 달성은 아직 미확인입니다.
음향/강화 반동은 기존 combat-impact-comparison-v1을 재사용합니다.
무료 팩에 효과음이 포함되어 있다는 의미가 아닙니다.
기관총은 기존 sim의 .22초 간격 10발, 함포는 기존 훈련용 함포 기록입니다.
피해량/충돌 범위/캠페인/장착 규칙은 변경하지 않습니다.

기존 comparison 원본은 보존하며 새 독립 경로에서 빌드합니다.
명령: node tools/free-pack-combat-demo-v1/build.cjs
검사: node tools/free-pack-combat-demo-v1/verify.cjs
의존성: 기존 work/combat-vfx-v2/deps의 three/esbuild를 읽습니다.

브라우저 보안 정책으로 자동 file:// 열기가 거부되어 우회하지 않았습니다.
실제 GPU 렌더·브라우저 재생·청취 검증은 수행하지 못했습니다.
verification.json은 CPU 장면/이벤트/프레임/수명 검사 결과만 담습니다.
유료 호출/결제/다른 채팅 메시지는 없습니다.
