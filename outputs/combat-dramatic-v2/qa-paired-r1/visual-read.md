# Cloudstitch · 함포 비교 화면 직접 관측

동결 source0.2.0과 delivery `c5a1711e1598f31302f4a9c9939bda5aedaefcdbed0dc7469348f6e24cfea06e`를 사용했다. 설치·재빌드·서버·실전 상태 변경 없이 지정된 Native Chrome 캡처 helper를 한 번 실행했다. 같은 camera/target에서 .19초와 .50초 두 장을 읽었다. 원본14개 payload와 읽기 의존성31개는 전후 해시가 같다.

- .19초: 작은 빈 꽃잎 대신 채워진 밝은 충격 덩어리와 두 비대칭 긴 획, 목재·산호색 파편이 명확하다. 원본의 작은 피격 효과와 선체에 버금가는 새 주형태의 차이가 보인다.
- .50초: 크림색 윗면과 짙은 세이지 밑면을 가진 두꺼운 연기층이 남는다. 최초 충격과 후속 여운을 서로 다른 형태·명암으로 읽을 수 있다.

이전0.1.1의 빈약한 질량 문제는 이 두 화면의 관측 범위에서는 해소됐다. 큰 질량·명암·연기의 최소 관측 목표를 충족해 실제 함포 연결 검수로 넘긴다. 사람의 미술·조작감 승인이나 ‘10배’의 계량 증명이 아니다. 표면 붓결은 선체 텍스처보다 단순하며, 새 실제 전투와 입력·HP·회수 검사는 별도다. 다른45종과 작살의 실전 기능까지 새로 완성했다고 표시하지 않는다.

캡처2장과 원자료 `capture.json`, 전후 해시·실제 재생 시각·helper·PNG를 결속한 `owner-provenance.json`을 보존한다. page/console/HTTP/실패/외부 요청 오류는 모두0이었다. helper exit0, finally browser close를 확인했다. 브라우저 종료는 시작 후37.3초 이내, 캡처·메타데이터 출력47.5초, 직접 읽기와 반환 보고까지87.2초였다. 추가 브라우저·export는 실행하지 않았다.
