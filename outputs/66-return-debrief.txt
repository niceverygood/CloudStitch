66. 귀환·보상 화면 — 무엇을 얻었고 무엇을 남겼는가
상태: 18번 경제·45번 저장·51번 UI 용어 계승. 디자인 시안이며 실제 UI 구현은 없음.

목표
전투의 흥분을 끊지 않으면서 회수품·구조 결과·지출·새 기록을 짧게 이해시킨다. 숫자 폭죽과 수십 번의 아이템 확인 버튼 대신 한 화면 요약과 필요한 상세 패널을 제공한다. 미션 결과 화면이 자동 수리·자동 판매·자동 저주 수락을 실행하지 않는다.

진입 흐름
항구 안전 경계 도착→진행 상태 저장 확인→3초 이내 짧은 계류 장면→결과 요약. 계류 장면은 건너뛰기 가능. 결과 확인 전에 앱을 종료해도 이미 확정된 회수품이 중복 지급되거나 사라지지 않도록 미션 정산 ID를 저장한다. 저장 실패 시 ‘저장하지 못함’과 재시도·현재 세션 유지 선택을 제공하고 성공한 척 진행하지 않는다.

첫 화면
상단: 미션 이름, 결과 ‘완료’ 또는 ‘귀환’, 소요 시간. ‘귀환’은 핵심 목표 미완료 상태에서도 안전하게 돌아왔다는 의미이며 무조건 실패 붉은 도장을 찍지 않는다.
왼쪽 큰 영역: 구조 인원·회수 핵심품·선택 목표. 인원은 정수와 이름 기록으로 표현하고 점수나 금액으로 환산하지 않는다. 구조를 하지 않은 미션에는 빈 구조 항목을 크게 노출하지 않는다.
오른쪽: 스크랩·연료·봉인 천의 실제 변동. 현장 획득, 현장 지출, 순변동을 구분한다. 항구 수리 견적은 아직 지불하지 않았으므로 아래 별도 카드에 표시한다.
하단: ‘함선 정비’, ‘회수품 보기’, ‘기록 보기’, ‘항구로’. 기본 포커스는 항구로. 새 기록이나 장비가 있다고 모든 패널을 의무로 열게 하지 않는다.

예시 정산
현장 스크랩 획득 150, 전투 수리 지출 20, 순변동 +130. 연료 출항 대비 -15. 항구 수리 예상 25는 ‘미지불 견적’으로 따로 표시한다. 정비를 확정하면 스크랩이 추가 -25되어 출항 대비 +105. 18번 평균 예시는 현장 수리 지출이 없는 다른 시나리오이므로 이 값을 평균 확정 수익으로 대체하지 않는다. 전리품 자동 판매 가치는 순변동에 더하지 않는다.

회수품 패널
‘온전한 부품’, ‘손상 부품’, ‘재료’, ‘기억이 남은 물건’ 필터. 부품 카드에는 종류·현재 내구도·무게·필요 전력·출처·현재 보관 위치를 표시한다. 희귀도 색만으로 구별하지 않는다. 새로 얻은 부품은 최대 3개 대표 카드와 나머지 개수로 압축한다. 상세에서는 전부 볼 수 있다.
행동: 보관, 정비함으로 이동, 분해 견적 확인. 분해·판매는 결과 미리보기 뒤 한 번 확정하며 직전 작업 취소 정책은 인벤토리 규칙과 통일한다. 장착하려면 편집 화면으로 이동해 부모 골조·부력·전력 확인을 거친다. 저주 물건은 ‘효과 미확인’과 조사 경로를 표시하며 자동 장착하지 않는다.

구조·선택 결과
구조한 인물이 항구 어디로 이동했는지 한 줄 제공한다. ‘급식소에서 회복 중’은 64번 해솔과 연결될 수 있다. 민감한 개인 기록을 전체 점수판처럼 나열하지 않는다. 선택한 행동의 관찰 가능한 결과만 쓰고 다음 막의 반전이나 숨겨진 호감도 점수를 미리 공개하지 않는다.
귀환 시 미완료 목표는 ‘남은 일’ 접힘 영역에 표시한다. 재출항 가능 여부, 현재 저장 지점, 완료한 조사 유지 여부를 정확히 안내한다. 이미 완료한 보상을 재획득할 수 있다고 표시하지 않는다.

입력·접근성
키보드·패드·마우스 동일 기능. 패드 좌우 이동은 카드 영역 경계를 명확히 하고 마지막 포커스를 복원한다. 자원 변화 애니메이션은 동작 줄이기 옵션에서 즉시 값 표시로 대체한다. 숫자는 자릿수 정렬, +/- 부호와 ‘획득/지출’ 단어 병행. 작은 글씨 장식 대신 큰 요약과 펼쳐 보는 상세를 사용한다. 모든 핵심 정보는 효과음 없이도 읽힌다. 비교 패널의 스크롤 위치는 주 결과 화면과 독립 유지한다.

스토리보드 6컷
1. 저녁 항구로 귀환하는 패치 기낭 비행선과 계류줄.
2. 따뜻한 계류 배경 위 어두운 크림색 글자 결과 화면, 세 줄 요약과 네 큰 버튼.
3. 함포·엔진·천·스크랩 카드가 나뉜 회수품 정리 화면.
4. 현재 스크랩 변화와 미지불 수리 견적이 분리된 정비 미리보기.
5. 급식소의 구조자와 새 기록 알림, 작은 인간적 귀환 장면.
6. 패드 포커스·큰 글자·동작 줄이기 변형을 같은 레이아웃에서 비교.
이미지 속 숫자와 문구는 시각 참고이며 위 정산 예시 및 18번 문서가 수치 기준이다.

제작 검증
실제 UI에서 획득과 수리 견적을 혼동하지 않는지, 정산 후 다시 불러와도 한 번만 지급되는지, 미완료 귀환이 패배로 오해되지 않는지 확인한다. 게임 구현과 저장 오류 실험은 아직 수행하지 않았다.
