01 시작 화면과 오프닝 — 기획 및 스토리보드 v0.1

목표
첫 30초에 세계의 비정상적인 부력, 어머니의 실종선, 아래를 향한 두려움을 전달한다. 시작 메뉴에서 최종 반전을 보여주지 않는다.

타이틀 화면
화면 우측 65%는 밤의 종항에 묶인 접합선. 누더기 부양낭은 미세하게 팽창하고, 갑판의 작업등 세 개 중 하나가 불규칙하게 꺼진다. 멀리 교회 모양의 항구가 거꾸로 매달려 있다. 카메라는 고정이며 작은 로프 흔들림과 구름만 움직인다. 좌측 어두운 여백에 검은 부력 로고와 메뉴. 전체 이미지에 빽빽한 글자를 넣지 않는다.
메뉴: 계속하기 / 새 항해 / 항해 기록 / 설정 / 종료.
저장 데이터가 없으면 계속하기는 비활성 처리하고 이유를 툴팁과 보조 설명으로 전달. 새 항해 선택 시 슬롯, 난이도, 조준 보조를 선택. 기존 저장 슬롯 덮어쓰기는 명확한 확인 단계. 초반 설정은 언제든 변경 가능하고 난이도 변경 제한이 있다면 화면에 공개한다.
이어서 하기 카드: 최근 항구, 임무명, 플레이 시간, 마지막 저장 시각, 함선 실루엣. 스포일러가 되는 저주나 등장 인물 정체는 숨김.
소리: 밧줄 마찰, 느린 금속 진동, 먼 종소리. 속삭임은 자막 및 별도 음량 조절 지원. 20초마다 공포 점프스케어를 반복하지 않는다.

시작 화면 상태
최초 진입 → 밝기와 자막 크기 간단 설정 → 타이틀.
새 항해 → 새 슬롯 → 접근성 사전 설정 → 오프닝 → 조작 가능한 갑판.
계속하기 → 저장 요약 → 최근 안전 체크포인트.
메뉴 뒤 배가 진행도에 따라 바뀌지만 새 게임 선택 시 초기 배로 돌아간다.

오프닝 6컷, 총 65초 내외, 스킵 가능
컷1 0~8초: 검은 화면, 무덤 아래 둔탁한 노크, 서서히 위로 떠오르는 흙덩이. 자막 '세상은 아직도 떨어지고 있다.'
컷2 8~18초: 낮은 구름 위로 매달린 항구를 지나가는 느린 카메라. 시체를 직접 설명하지 않고 검게 봉인된 부력 통과 장례행렬을 교차 배치.
컷3 18~29초: 주인공 작업대에 무인선 입항을 알리는 황동 표식이 놓임. 어머니의 선장 휘장과 같은 문양.
컷4 29~41초: 무인 접합선 갑판. 식탁의 따뜻한 수프, 끊어진 밧줄, 빈 의자. 사람은 보이지 않음.
컷5 41~55초: 선장실 문에 '내 목소리가 들리면 배를 버려라'. 손이 문에 닿자 안쪽에서 한 번 두드림. 대사 없이 소리로 전달.
컷6 55~65초: 선체 밑에서 낮은 진동. 카메라가 갑판의 주인공 뒤로 이동한 뒤 게임 시점으로 올라감. 목표 '감정사를 찾아 배의 상태를 확인하라'.

초기 조작 구간
이동과 상호작용만 먼저 제공. 감정사가 총을 꺼내는 장면은 대화 중 시각적 복선 이후 발생. 항구 화재를 계기로 조타석 탑승 → 기동 튜토리얼. 오프닝부터 모든 성장 화면을 보여주지 않는다.

무드보드 제작 사양
상단 대형 타이틀 UI 콘셉트 1컷, 하단 오프닝 6컷. 좌측 메뉴 여백, 우측 부유선. 색은 남색·청록·황토·작업등 주황. 새 항해, 계속하기 등 짧은 한국어 UI. 최종 반전과 신의 형상은 제외.

확인 기준
타이틀 글씨는 배의 복잡한 선체와 겹치지 않음. 메뉴가 1080p에서도 읽힘. 색 이외의 선택 강조 사용. 스킵 후 첫 목표와 조작을 이해할 수 있음. 화면 흔들림과 섬광을 설정에서 끌 수 있음.
