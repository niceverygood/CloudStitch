효과 아트에 전달할 최소 계약
- event: seq/type/projectileId/weaponId/x/y/z/direction, hit에는 실제 normal. position 객체는 API 원문 필드가 아님.
- asset: 기존 effect ID 또는 명시 매핑, model 상대경로, clip/duration/loop, SHA-256/작업 출처.
- axis: 효과 +Z 진행, +Y 위; 피격 +Y 법선, +Z 진행 접선.
- 리그 원시 Muzzle은 -X. assets.js의 muzzleFrame()이 월드 방향으로 이미 변환함. 원시 quaternion 직접 복사만 피함.
- projectile: 현재 전장은 effectId_projectile_carrier_0 노드만 사용. 내장 비행 animation을 중복 실행하지 않음.
- lifecycle: load/consume/update/reset/dispose/debug. pause dt0, retry/depart reset, projectile-ended/상태 종료 반영.
- clear 뒤 one-shot 잔류 가능성은 VFX API 단독 사용의 한계다. 기존 통합 renderer는 combat-cleared에서 effects.reset()하므로 그 경로의 잔류 결함으로 단정하지 않음.
- pool 반환: action/mixer/time/child·root 변환/parent·host·끝점 참조 초기화.
- 현재 실제 런타임은 기관총·훈련 함포의6 GLB 연결. 새 대표6종 아트와 전체48효과 통합은 별도 범위.
- 현재 필수6GLB와 대표6아트는 서로 다르다. 직접 교체는 machine-gun-muzzle/cannon-hit이며 effect별 선택+v1 fallback이 필요하다.
- smoke/shield/repair/flame은 host/state 수명 소비가 별도 필요하다. 새 전장 문서 VFX-V2-INTERFACE.md에 실제 제약을 인계했다.
- 플레이어는 실제 Muzzle resolver를 쓰지만 현 적 함포는 모듈 평면 중심+y1.3의 근사 포구다. 적까지 실제 무기 끝점 검증이 완료됐다고 쓰지 않는다.
