Cloudstitch · 4성 귀환호 3계열
직접 요청: 4성급도 세 계열 모두 제작, 3성과 비교해 장착물 변화가 확실하게 보이게 한다.
이전3성 원본과 실제GLB/HTML/manifest는 읽기 보존한다. 과거 모델이나 공통런타임/게임데이터는 수정하지 않는다.

교체되는 주력 장착물
기동: 3성의 높은 가변 안정돛을 제거하고 하부에 좌우 3분절 활주판을 펼친다. 하부 방향타와 높은 분할 꼬리 안정돛,
재배치한 좌우 후방 추진대가 낮고 넓은 실루엣을 만든다. 기존3성의 상부 돛을 모두 더한 증축형이 아니다.
포격: 삼실 회전 약실/후방 회전 급탄부를 제거하고 단일 포신의 긴 반동 레일·피스톤·개방형 방패·하부 지지구로 교체.
포신 수/공격력 증가 대신 후퇴하는 포가와 반동을 버틸 장착 구조를 시각적으로 제안한다.
인양: 전개된3성 크레인과 매달린 슬링을 제거, 작은 수납형 후방 고리팔과 선수의 벌어진 완충 회수 레일로 재배치.
선체 밑의 케이블 화물 플랫폼/받침으로 인양 후 임시 적재의 실루엣을 만든다.
목재 상자는 예시 화물 메시로 자원/보상 지급이나 실제 적재 판정을 확정하지 않는다.

실제 에셋
star4-mobility.glb / star4-artillery.glb / star4-salvage.glb
원형+4성 root scale1, 동일 +Y 위/-X 선수 좌표. 기낭과 핵심 목재 선체 전체를 단순 확대하지 않는다.
원래 손그림 아틀라스와 새 목재/천/도색금속 grain, 버텍스 명암, KHR_materials_unlit이 GLB 안에 포함된다.
GLB는 정적 전개 포즈, 애니클립 없음. 도크/분절판/포가의 펼침·반동 시퀀스를 제작한 자산은 아니다.
HTML의 윤곽선·셀 명암·프로펠러 재생은 runtime이며 외부 엔진으로 GLB만 이동하면 자동 재현되지 않는다.

같은 조건 비교
index.html은 왼쪽 동결3성GLB/오른쪽 새4성GLB를 하나의 카메라·같은 배율·같은 조명에서 보여준다.
선택 계열별 변경 내용을 짧게 표기하며 GLB3 실제 다운로드를 제공한다.
참고 무드보드의 정밀 복원이 아닌 코드로 직접 모델링한 장착 구조 형태 시안이다.
미터/표준소켓/기구학/충돌/손상연결트리/하중·양력·전력·포각/LOD 최적화는 별도다.
실제 게임 성급/승급 지급/무기·수리·인양 동작/저장 기능은 변경하지 않았다. 장치의 개수는 게임 수량 확정이 아니다.
