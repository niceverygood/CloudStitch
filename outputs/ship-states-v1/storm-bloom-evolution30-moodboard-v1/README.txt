기획 방향
Lv.1–5: 세 장의 꽃잎 돛과 나침반 선수, 보강대·발코니·보조 추진·상층 선실.
Lv.6–10: 다섯 꽃잎 돛, 선체 확장·하부 공방·쌍 추진기·회랑.
Lv.11–15: 생활 공방·정원·보일러·장비 거치대, 일곱 꽃잎 프리깃.
Lv.16–20: 좌우 보조 선체·풍차·다층 선실, 공중 마을 순양선.
Lv.21–25: 선수 차양·날개 돛·온실·등대, 아홉 꽃잎 지휘선.
Lv.26–30: 바깥 꽃잎 층·추진 왕관·매달린 정원·전개 골조, 완성형 폭풍꽃 기함.

각 레벨의 구체 장비 수/형태는 이미지 생성 기반 아트 탐색이며 확정 시스템 명세가 아니다.
연속된 30단계의 디자인 방향을 제시한 2D 무드보드. 3D 모델/실제 성장/스탯/장착/저장은 구현하지 않음.
기존 기본형과 무드보드/3D 뷰어는 보존. 사람의 미술 승인과 기술 파일 확인은 구별한다.
