Cloudstitch · 모빌리티/인양 계열 재디자인
최신 사용자 요청: 모빌리티랑 salvage 모델 다시 만들어줘.
무드보드 검토 중인 맥락에 따라 두 계열의 2D 외형 모델 시안을 다시 설계한다. 포격 계열과 기존 파일은 보존한다.

모빌리티 · 바람길잡이
긴 바늘형 기수/환형 터빈 대신 실제 목재 배의 들린 선수, 곡선형 기낭, 뒤로 휘는 제비형 안정돛을 중심으로 한다.
크림 기낭과 청록 선장실을 유지하고 황동 가동 골조 위의 천/목재 안정날개로 항해 감성을 강화한다.
2성 작은 곡선 안정날개/강화 프로펠러 → 3성 넓게 펴는 날개/곡선 기낭 → 4성 이중 안정날개/쌍 추진 → 5성 완성형 바람 항해선.

인양 · 구름 예인선
기낭 위를 감싸는 거대 집게 대신 둥글고 든든한 예인선 선체, 큰 측면 케이블 드럼, 선수 U자 회수 받침을 중심으로 한다.
후방/측면에 낮게 접히는 크레인과 고리/슬링, 얕은 하부 화물 받침, 작은 수리 작업대를 연결한다.
2성 윈치/회수 받침 → 3성 깊은 화물 선저/측면 크레인 → 4성 복합 윈치/열린 수리 갑판 → 5성 완성형 공중 예인·정비선.
회수 받침은 공격 집게/충돌 무기로 확정하지 않는다. 회수와 적재·제작·장착 상태는 구별한다.

공통
원래 귀환호의 크림 기낭·꿀빛 목재·청록 기계/지붕·황동·산호색 천을 유지한다.
일반 경험치 레벨업과 성급별 테크트리 선택의 구조는 유지하며 임시 승급 레벨을 확정하지 않는다.
2~5성×두 계열=8개 대표 외형. 기계 구조와 장비 수는 생성 이미지 기반 시각 탐색이며 규칙 명세 아님.
내장 image_gen 사용, 전체 프롬프트 prompt.txt. 3D 자산/실제 성장·장착·전투·저장은 구현하지 않는다.
