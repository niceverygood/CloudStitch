열기
이 폴더의 index.html을 브라우저에서 엽니다. 원본 GLB와 Three.js가 내장되어
서버·CDN·인터넷 연결 없이 file://에서도 작동합니다. 31개 썸네일은 시작할 때
내장 3D로 직접 렌더링합니다. 첫 로딩은 기기에 따라 잠시 걸립니다.

보는 방법
- 상단 6개 카드: 평소 / 피해 / 무기 / 방어구 / 성장 / 에너지 0 폭발.
- 카드·단계 버튼·하단 전체 도감: 해당 모습을 확대 비교 작업대에서 선택.
- 왼쪽은 원래 함선, 오른쪽은 선택 단계. 같은 카메라·배율로 비교합니다.
- 드래그 회전, 휠 확대, 오른쪽 드래그 이동, 화면 맞춤, 초기 시점, 자동 회전.
- 손그림 / 셀 명암 / 원본 재질, 윤곽선, 크림 / 짙은 청록 배경.
- 재생·일시정지·처음부터·시간 스크럽·반복·속도. 폭발은 0~4초 타임라인.
- 비교 화면 PNG는 현재 두 화면을 저장합니다. 선택 모습 GLB는 현재 포즈를
  별도 정적 GLB로 저장합니다. 원본 및 런타임 애니메이션을 덮어쓰지 않습니다.

        화물 선반, 관측갑판, 쌍기낭, 누적 완성까지.
폭발5: 에너지 소진0초 / 점화0.65초 / 폭발1.3초 / 파열2.3초 / 잔해3.8초.
목록과 고유 ID, 바로 가기는 catalog.json에 있습니다.

제작과 보존
선택 원본 outputs/selected-airship-toon3d/airship.glb의 11,026삼각형과 텍스처를
보존하고 기존 part-map으로 원본 연결 섬을 부위별로 나눠 표시합니다.
원본 파일을 수정하거나 새 유료 모델/이미지를 생성하지 않았습니다.
추가 갑판·무기·장갑·기낭·화염·연기는 코드로 만든 입체 형상입니다.
기존 weapon-modules의 제작된 무기 GLB를 교체한 것이 아닙니다.
성장 모습은 전체 함선을 크게 확대하지 않고 실제 부품을 누적 추가합니다.

한계
실제 전투·충돌·HP·장착 호환·경제·저장·성장 시스템과 연결하지 않았습니다.
피해율·장갑 단계·무기 조합·Lv1~9 변화는 외형 검토안이며 확정 밸런스가 아닙니다.
사용자가 요청한 에너지 0 폭발은 독립 시각 이벤트입니다. 양력0·전력0·연료0의
정식 게임 규칙과 동일시하지 않습니다. 폭발 파편은 물리가 아닌 작성한 궤적입니다.
손그림/셀/윤곽선과 재생은 HTML 런타임 기능입니다. 내보낸 GLB는 선택 순간의
정적 포즈이며 엔진용 애니메이션 클립·충돌·LOD·공통 셰이더가 포함되지 않습니다.
브라우저 검사는 verification.json, 최초 실패는 initial-verification.json을 따릅니다.
파일/표시 검사를 실제 게임 플레이·최적화·미술 승인으로 해석하지 않습니다.

최종 검수 범위와 남은 제한
finish-verification.json: 실제 부품 행렬·재질·카메라의 순/역 탐색 동일,
31개 미리보기와 데스크톱/390px 잘림 없음, 4초 종료·재시작 통과.
followup-verification.json: 세 모드120프레임 회전 잔상 차이0, 실제 GLB/PNG 저장,
390/768/1440px 넘침 없음, 오류·외부 요청 없음. 이전 HTML에서의 범위를 보존합니다.
최종 한 줄 수정은 투명 효과의 미리보기 윤곽선을 끄는 조건이며,
capture-verification.json과 overview.png로 별도 확인했습니다.
일부 폭발 프레임은 행렬·재질·카메라가 같아도 다시 렌더링하면 일부 픽셀이
달라집니다. 렌더링 없는 연속 이미지 읽기는 같습니다. 원인은 아직 미확정이며
정밀 픽셀 일치 검사는 FAIL로 보존했습니다. 허용치로 PASS 처리하지 않았습니다.
delivery-manifest.json은 이 한계를 포함한 ART-REVIEW 인계입니다.
이 버전은 이후 수신한 ‘10배 이상 과감한 표현’ 기준의 최종 이행으로 표시하지 않습니다.
