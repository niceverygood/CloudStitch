Cloudstitch · Lv.1–30 진화 도감

index.html을 브라우저에서 엽니다. 모델과 코드가 내장되어 오프라인으로 작동합니다.
30개의 실제 외형 단계를 5레벨씩 여섯 구간으로 전시합니다.
레벨 슬라이더/앞뒤 버튼/1→30 자동 진화, Lv.1·직전 레벨·기존9단계 최종형 비교,
회전·확대·재생·세 재질 모드·정적 포즈 GLB/PNG 저장을 제공합니다.

진화는 원래 함선 전체를 키우지 않고 구조물을 누적하는 방식입니다.
Lv.1–5: 선수 보강, 양측 작업 갑판, 쌍 보조 추진.
Lv.6–10: 쌍 보조 기낭, 화물 선체, 선수 전망대, 선미 항해실.
Lv.11–15: 횡단 작업교, 외측 추진기, 생활관, 공방, 큰 바람돛.
Lv.16–20: 삼중 선체, 상층 쌍기낭, 선미 풍차, 공중 연결관.
Lv.21–25: 길잡이 선수, 비대칭 쌍돛, 항로 등대, 대형 하부 선체.
Lv.26–30: 왕관 기낭, 하늘 회랑, 구름 정원, 바람고리, 선수 왕관돛.

원래 선장실·산호 패치·크림 기낭을 유지하며 꿀빛 목재·청록 지붕·황동·봉제 천을
여러 높이의 실루엣과 생활 장치로 확장합니다. 30단계의 정적 추가 면은 재료별로
병합해 표시하고 프로펠러는 별도 회전합니다. root 전체 배율은 항상1입니다.

실제 게임 레벨·스탯·장비·양력·저장 규칙은 변경하지 않았습니다.
30단계는 논리 외형이며 30개 원본GLB/완성 엔진 자산을 생성한 의미가 아닙니다.
내보낸 GLB는 현재 정적 포즈이며 HTML의 동작/셀·윤곽 셰이더는 포함하지 않습니다.
기존9성장형과 v1/원본/검사 실패·성공 기록은 보존합니다.
새 이미지/유료 Meshy/배포/자동화/commit/push는 없습니다.
source-verification.json은 실제GLB 기반 기하·누적·루프 검사입니다.
브라우저 검증은 ../dramatic-v2/verification.json의 evolution30Viewer 범위를 따릅니다.
6유형 전체를 더 과감하게 다시 구성한 화면은 ../dramatic-v2/index.html입니다.
