Cloudstitch · 귀환호 성급과 테크트리 외형 진화 제안

최신 사용자 방향
폭풍꽃 형태와 과도한 30단계 증축 대신 처음 선택한 귀환호로 복귀한다.
적 처치와 경험치 수집 → 일반 레벨업의 스킬/무기 강화 → 특정 레벨의 성급 승급 → 선택 테크트리에 따른 선체 외형 진화.
기존 무드보드는 탐색 이력으로 보존하며 최신 선택안으로 취급하지 않는다.

일반 레벨과 성급
- 일반 레벨: Lv.1–30 검토안. 레벨업 때 스킬 강화 또는 장착 무기 강화 중 하나를 선택하는 흐름을 제안한다.
- 무기 강화는 포신/장전부 같은 장착 장비 외형에 작게 반영할 수 있다. 일반 레벨마다 선체 전체가 자동 증축되지는 않는다.
- 성급: 큰 구조 개조가 열리는 이정표. 승급 조건 충족은 자격 해금이며 선택 확정 전에는 외형을 자동 변경하지 않는다.
- 승급 레벨 후보: 1성 Lv.1, 2성 Lv.6, 3성 Lv.12, 4성 Lv.20, 5성 Lv.30. 실제 경험치 곡선·출항 길이·밸런스 검증 전 임시 수치다.
- 2성에서 주계열을 선택, 3–5성에서 해당 계열의 다음 개조 노드를 선택한다. 무드보드는 각 계열의 대표 단일 경로만 보여준다.
- 후속 선택지 예: 기동=순항/회피, 포격=정밀/일제, 인양=회수/현장수리. 이번 보드는 이 하위 분기 전부를 확정하거나 그리지 않는다.
- 장갑은 보조 선택으로 두어 테크트리마다 활용 가능하게 제안한다. 보조 선택이 주계열 실루엣을 가리지 않도록 한다.
- 계열 재선택은 항구 개조 화면에서 미리보기·효과/장비 호환 확인 후 확정하는 방안을 권한다. 비용·초기화 범위는 미정.
- 기존 장착 무기를 전부 자동 교환하거나 새 장비를 무료 지급하는 뜻이 아니다. 개조 기능/장착 공간 해금과 회수·화물·제작·장착은 구별한다.

대표 테크트리 외형
공통 1성: 크림 기낭 하나, 갈색 띠, 꿀빛 목재 선체, 청록 선장실과 후방 프로펠러.
기동 2/3/4/5성: 소형 보조 추진 → 꼬리 안정판 → 쌍 추진 받침 → 유선형 선체와 정돈된 고효율 추진.
포격 2/3/4/5성: 선수 포대 보강 → 넓은 작업갑판/탄약함 → 반동 지지대/보조포 → 짧은 방호판과 안정된 주포 플랫폼.
인양 2/3/4/5성: 윈치 → 접이식 크레인 → 하부 화물 받침 → 정리된 회수·수리 작업선.
후반에도 한눈에 원래 귀환호임을 알아보게 한다. 기낭 추가·다중 선체·도시 증축·꽃잎 돛은 이번 안에서 사용하지 않는다.

기존 기획과의 관계
outputs/112-system-rules-reference.txt와 114-production-decision-register.txt는 기동·포격·인양 3계열,
출항 Lv.1–9/8포인트/21노드 초안을 기록한다. 새 Lv.1–30/성급안은 최신 요청을 반영한 교체 검토안이며
그 수치와 동시에 확정 운영한다고 쓰지 않는다. 기존 Q/E/R 슬롯·궁극 조건·포인트 수의 이행은 별도 결정이 필요하다.
경험치 필요량·강화 선택의 횟수/상한·장착 공간·무게/양력·전력·포각·세이브 이행은 미확정이다.

산출물과 검증
내장 image_gen으로 제작한 2D 외형 방향 무드보드. 전체 프롬프트 prompt.txt.
공통 1성1척 + 3계열×2–5성4척 = 총13개 대표 외형을 의도했다.
생성 이미지의 장비 수·구조·문자는 시스템 규칙의 근거가 아니다. 실제 결과의 배열과 라벨은 별도 육안 확인한다.
3D 모델·경험치/승급/스킬/실제 장착·전투·저장 기능은 이번에 구현하지 않았다.
원래 귀환호와 기존 뷰어·무드보드는 보존한다.
