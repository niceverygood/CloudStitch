Cloudstitch · 3성 귀환호 세 계열
직접 요청: 3성급도 만들어줘. 최신 성급별 장착물 전환 무드보드의 세 계열을 실제 GLB로 제작.
기존 원형/2성 모델과 모든 이전 시안은 읽기 보존한다.

기동: 고정 안정돛 받침을 관절/가동 골조로 교체하고 서로 다른 각도의 안정돛 비행 포즈를 모델링.
원 단일 후방 엔진과 프로펠러를 숨기고 좌우 독립 틸트 받침/기어·쌍 추진기로 대체.
포격: 2성 단포를 삼실 회전 약실 개념 포대로 교체. 실제 총열은 전방 활성 포신 하나이며 후방 급탄 캐러셀과 넓은 방호판을 더한다.
인양: 2성 U자 받침을 선수 로프 가이드로 교체. 측면 윈치는 유지하고 후방/측면 접이식 크레인, 고리와 네 줄 슬링/얕은 플랫폼을 설치.
모든 변화는 형태와 장착 구조의 검토안이며 실제 사격·재장전·인양 판정/테크트리 지급 규칙의 구현이 아니다.

표현과 파일
star3-mobility.glb / star3-artillery.glb / star3-salvage.glb
원 손그림 아틀라스/새 목재·천·금속 붓결 텍스처/정점 단순 명암/KHR_materials_unlit을 GLB 내부에 포함한다.
윤곽선·선택 셀 명암·프로펠러 움직임은 index.html의 런타임 기능. GLB는 정적 포즈이며 animation clip을 포함하지 않는다.
독립 GLB 재질은 외부 엔진에서 지원하는 unlit/vertex colour 범위에서 재현된다. 뷰어 윤곽선은 자동 이식되지 않는다.
2성 같은 계열과 3성을 같은 카메라/배율로 비교한다. 기존2성 GLB3개는 뷰어에 읽기 임베드한다.
root scale1, 축+Y 위/-X 선수. 원형 좌표 단위로 미터/표준 장착 소켓/충돌/LOD는 미정이다.
작은 가동부 이름/원점은 시각 검토용이며 엔진용 손상/장착 트리·리깅 확정이 아니다.

검사
source-verification.json: 원선체 SHA, 실제 기하 유한값/형상/scale/프로펠러 루프 확인. 브라우저 검사 아님.
verification.json이 존재하고 passed=true일 때에만 실제 GLB export/reload·세 모드·잔상·조작·반응형 검사를 통과한 것이다.
원화의 정밀 복원 모델이 아닌 코드로 직접 모델링한 형태 시안. 기술 PASS와 사용자 미술 승인은 구별한다.
실제 게임 레벨·성급·스탯·사격·수리·저장 연결0, 유료 생성/설치/commit/push/배포0.
