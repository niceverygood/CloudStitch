Cloudstitch · 귀환호 1~5성 전체 보완 v2
직접 요청: 5성을 만들고 1~4성도 더 풍성하고 극적으로 보완. 보스 참고의 큰 질량·선수 조형·겹구조 강도를 세 계열 전체에 적용.
공통1성1 + 2~5성의기동/포격/인양12 = 실제GLB13. 1성은 공통 출발선이며 그 다음부터 계열이 갈린다.
기존 원형/2성/3성/4성 GLB/HTML/manifest와 소스는 보존한다. 별도새revision이며 기존 에셋을 덮지 않는다.

전 성급 공통 보완
꿀빛 선저의 실제 입체 질량, 양옆 곡선 골조, 사격선 아래의 구름 두루마리형 선수, 항해등, 작은 후방 항해실을 새로 모델링했다.
원 크림 기낭/선장실의 중심정체성과 원형부품 좌표를 유지한다. root1, 원기낭scale1, 핵심 선체를 단순 전체확대하지 않는다.
첨부 보스의 고유 검은 선체/이빨/색을 복제하지 않고 큰 조형물과 층의 강도를 참고했다.

단계별 장착 변화
기동2성 고정돛/보호추진틀 → 3성 가변돛·기어박스/틸트추진 → 4성 하부분절활주판/높은꼬리돛 → 5성 이중부채안정돛/높은쌍추진대.
포격2성 단포/둥근방호 → 3성 회전약실/측면급탄부 → 4성 단포반동레일/전개지지대·후방균형추 → 5성 통합쌍포/장전부·중첩장갑.
인양2성 U예인받침/완충패드 → 3성 굴절크레인·보강타워/슬링 → 4성 회수도크/롤러갠트리·하부플랫폼 → 5성 측면정비팔/개방공방·화물받침.
3성의 약실/슬링/가변돛을 이후에도 모두 누적하는 설계가 아니라 원 주력장치의 전환을 유지한다.

뷰어
직전 성급과 같은 카메라/조명/상대단위로 비교한다. 공통1성은 원래 귀환호와 비교.
계열/앞뒤 성급 선택, 13개 카드 도감, 실제 GLB 다운로드, PNG, 손그림·셀·GLB재질, 윤곽선, 회전·맞춤·프로펠러 재생.
원손그림 아틀라스/새붓결 텍스처/정점단순명암/KHR_materials_unlit은 GLB에 포함.
윤곽선·셀명암·프로펠러재생은 HTML runtime, GLB애니클립0. 가변/반동/인양 작업 동작은 정적 검토포즈다.

미확정/소비 경계
원좌표 +Y위/-X선수/root1. 미터·게임소켓·충돌·LOD·하중/양력·전력·포각·정밀기구학은 미정.
원선체 크기유지와 새 큰 부속이 만드는 외곽크기는 구별한다. 5성기동은 104,891삼각형의 형태검토안으로 게임성능예산 확정값이 아니다.
부품수/포신수/생성그림의표시는 피해량·장비슬롯·공격규칙 확정이 아니다. 실제 성급/스킬/레벨/인양판정/저장 연결0.
향후별도무기 검토는 포격주력포와 중복누적을 피하고 기동날개/추진통로·인양회수통로를 보존해야 한다.
원기준좌표의 검토용 공간이며 이 작업으로 새장착소켓/무기합성은 구현하지 않았다.
