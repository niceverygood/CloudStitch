공통1성 + 세 계열 2~5성 = 실제 13형상. 기존 v2 원형은 보존.
성급마다 이전보다 최소1.5배 풍성함은 미술 설계 목표. 2성부터 설계 선체 길이1.6배/성급, 새 갑판·부양낭·계열장치로 성장. 실제 외곽길이 전단계 최소1.58배. 부피/삼각형수/눈에 느끼는 풍성함을 동일 배수로 취급하지 않는다.
기동: 1→4쌍 활공돛, 추진기, 4성부터 보조기낭. 포격: 단포→회전약실→공성포→대형쌍포와 중첩 장갑. 인양: 예인받침→관절 크레인/화물→회수도크→복층 공방.
비교창은 직전 성급과 같은 카메라/축척. 도감 카드는 각자 화면 맞춤.
단위는 원본 상대좌표, root scale1. 실제 미터·충돌체·LOD·게임수치·승급·저장 연결·실가동 크레인 아님.
GLB에는 손그림 unlit/정점명암/재질 포함, 윤곽/셀명암/프로펠러회전은 뷰어 기능.
기존 COLOR_0 1초과 문제는 이 버전의 복제 지오메트리에서만 clamp, 동결 원본 변경0.
