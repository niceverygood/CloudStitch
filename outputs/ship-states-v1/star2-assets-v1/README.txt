Cloudstitch · 2성 귀환호 3계열 독립 3D 에셋

직접 사용자 요청: 최신 성급별 장착물 기획의 2성급을 2D 느낌의 3D 에셋으로 제작.
기동/포격/인양 세 계열을 같은 원형 선체에서 제작. 원래 GLB와 모든 이전 뷰어는 보존.

모델
star2-mobility.glb: 곡면 크림 천 안정돛, 청록 곡선 끝단, 황동 전개 지지대, 올라간 목재 선수.
star2-artillery.glb: 원 기관총을 새 짧은 선수포로 교체, 실제 어두운 포구/황동 테두리, 작업갑판과 반동 받침/짧은 방호판.
star2-salvage.glb: 원 소형 윈치를 큰 측면 케이블 드럼으로 교체, 열린 U자 완충 회수 받침과 작은 수납형 고리 지지대.
정적 포즈 GLB. 3성 이상의 큰 가변 장치/작업팔을 선행 장착한 것이 아니다.

표현
원형의 기존 손그림 텍스처는 그대로 읽기 사용. 신규 곡면·골조·봉제선·두른 로프는 실제 3D 기하다.
신규 재질의 명암/미세 색 변화는 버텍스 색으로 저장하고 MeshBasicMaterial/KHR_materials_unlit로 내보낸다.
원형 아틀라스도 조명에 덜 좌우되는 unlit 재질로 복제해 저장한다. 원본 텍스처/파일은 변경하지 않는다.
윤곽선과 선택형 셀 명암은 HTML 런타임 효과이며 GLB를 외부 엔진에 넣는 것만으로 자동 재현되지 않는다.
프로펠러 재생은 이 뷰어의 런타임 동작이고 GLB 애니메이션 클립은 없다.

제작/소비
재사용 소스: tools/ship-states/star2-assets-v1/models.js
오프라인 비교 뷰어: index.html (원형1성/선택2성을 같은 배율로 비교)
다운로드한 GLB는 자체 메시/재질/색/아틀라스를 포함하며 외부 텍스처 요청을 요구하지 않는다.
축 +Y 위 / -X 선수. 원형 좌표 단위이며 미터 치수·게임 표준 소켓은 확정하지 않았다.
이름 붙은 장착물 그룹은 검토용 분리 단위다. 손상 트리/충돌/LOD/엔진 리깅/HP·성급·장착 규칙/세이브 연결은 별도다.
성급별 재료비·중량·양력·전력·포각을 실제 게임에서 검증한 자산으로 표시하지 않는다.

검사
source-verification.json: 실제 원 GLB 기하에 대해 유한값/형상 차이/전체scale1/프로펠러 루프 검사.
verification.json: 생성될 때에만 실제 GLB export/reload/세 모드/회전잔상/조작/390·768·1440/외부요청 검사 결과를 뜻한다.
해당 report가 없으면 브라우저/실제export 검증 대기 상태다. 미술 승인은 별도.
유료 생성/API·설치·배포·commit·push 없이 코드 모델링과 기존 로컬 의존성을 사용한다.

첫 브라우저 검사는 GLB3/9모드/3×120프레임 잔상0/조작/모바일/외부요청0 PASS였습니다.
실제PNG 확인에서 신장착물의 평탄한 표면이 원아틀라스에 비해 단순하여 붓결 재질을 추가했습니다.
초기 결과·GLB·HTML·PNG·models.before.js는 qa-initial/에 보존합니다.
새 목재/천/도색금속 grain 텍스처도 GLB 내부에 포함합니다. 기동 선수의 작은 조각선과 포신 청록 몸통도 보강했습니다.
재질 수정 후 실제export/reload9표시 결과는 verification-materials.json에 별도로 남깁니다.
변경 없는 뷰어의 조작/반응형/불투명 잔상 검사는 원 실행 근거를 상속하며 새 전체 검사를 했다고 주장하지 않습니다.
