88. 1막 컷신 샷리스트 — 종항을 떠나기 전
상태:23번 임무 순서·10/68번 보스·78번 이후·83번 일상 계승. 영상 제작이 아닌 샷 기획과 이미지 참고다. 시간은 편집 목표 가설.

공통 제작 규칙
플레이어가 만든 배·선장 외형·현재 동료를 사용한다. 정해진 다른 주인공 얼굴을 고정 영상으로 대체하지 않는다. 안전 장면에서만 짧은 전경 카메라를 사용하고 조작 복귀 전 전투55도 방향을 되돌린다. 모든 컷신 건너뛰기 가능. 필수 사실·현재 목표는 일지 요약으로 남긴다. 어머니 정체와 주인공 부활은1막에 공개하지 않는다.

S01 종지기의 부탁 /25~35초 후보
A 넓은 항구와 늘어진 상승 사슬, 주민이 보강재를 옮긴다.
B 종지기 손이 낡은 압축기 설계 표시를 짚는다.
C 선장 어깨 너머로 의뢰 지도, 난파선 좌표 핀.
대사: ‘종은 시간을 알리는 게 아니오. 우리가 아직 여기 있다는 걸 알리는 거지.’
플레이 복귀: 게시판 또는 항로 준비 화면. 짧은 대화만 보고 자동 출항하지 않는다. 이 시점 종의 위치와 도난 시점은 기존1막 이벤트 기준으로 배치하고 사건 후 빈 종틀 버전을 재사용하지 않는다.

S02 살아 있는 난파선 /15~20초 후보
A 접근하는 귀환호와 난파선 외부 압축기.
B 창 안쪽의 성인 승객이 천천히 신호한다. 기괴한 얼굴로 괴물 정답을 먼저 주지 않는다.
C 압축기 연결부와 난파선 양력 상태를 함께 보여 준다.
플레이 복귀: 승객 이송/통째 견인/지원 요청 선택. 각 대안의 공간·위험을 짧게 설명한다. 압축기를 떼면 어떤 상태가 되는지 먼저 알린다.

S03 잠들지 않는 손님 /30초 이내 후보
A 늦은 항구 급식소, 앉아 있는 성인 손님과 따뜻한 컵.
B 명부의 오래된 날짜와 현재 기록이 나란히 보임. 작은 글자는 별도 큰 자막 정보로 제공.
C 종지기와 죽은 아내를 닮은 여성이 서로를 본다. 짧은 침묵.
대사: ‘당신은 나를 두 번 묻을 거예요?’
플레이 복귀: 조사 노드와 일지. 모든 승객을 자동 적으로 바꾸거나 강제 사격시키지 않는다.

S04 두 개의 숨 /20~30초 후보
A 현장 사제 또는 연합 도구 담당자가 분리 안정 장치를 놓는다. 실제 선택한 접근 경로만 등장.
B 마라가 손으로 장치 고정 상태를 확인한다.
C 귀환호 아래 닫힌 해치, 오래된 자장가의 짧은 흔적. 자막은 소리 발생만 제공하고 화자의 정체 확정은 피한다.
플레이 복귀: 안정장치 운반·설치. 기억 장면은 메뉴·저장을 방해하지 않는다.

S05 종이 울리기 전에 /20초 후보
A 보강 계류줄·수리재료·외곽 경고종 중 실제 준비한 두 항목을 보여 준다.
B 민간선이 안전 통로로 이동, 오르가 포대를 확인.
C 멀리 장례전함 실루엣, 선장의 현재 배 전경.
대사: ‘대포는 내가 볼 테니, 네가 돌아올 길이나 봐.’
플레이 복귀: 최종 장비 확인과 출격 선택. 저장 없이 보스전 자동 시작 금지.

S06 종을 삼킨 자 등장 /15~25초 후보
A 빈 큰 종틀을 지나 전함 선체의 큰 종을 본다. 도난 사건이 완료된 상태의 배경만 사용.
B 천 가리개가 올라가고 측면 포신이 드러난다.
C 플레이 카메라로 돌아오며 첫 포격 예고가 시작된다. 카메라 전환 중 공격 판정으로 피해를 주지 않는다.
플레이 복귀:10번1단계. 종소리와 무관하게 포신·HUD·공간 예고가 있다.

S07 열린 길 /20~30초 후보
78번 구조 통로→민간선 통과→주민 이름 확인 순서. 보상 팝업은 이동을 가리지 않는다. 빈 종틀 아래 작은 파편 신호대는 전투 후 버전에만 놓는다. 실패 재시도 때 긴 성공 장면을 먼저 재생하지 않는다.

S08 첫 완전한 식사 /30~45초 후보
A 익숙한 식탁과 실제 합류한 동료의 컵.
B 주인공 앞에 놓인 ‘어머니의 도면을 알고 있다’는 연합의 제안.
C 선장 휘장과 배의 수선 흔적, 창밖 다음 항로.
플레이 복귀: 항구 정비·동료 대화·다음 출항. 즉시2막으로 강제 이동하지 않는다.

대표 무드보드6컷
종지기와 압축기 지도 / 성인 난파선 승객 신호 / 오래된 날짜와 잠들지 않는 손님 / 안정 장치와 닫힌 해치 / 장례전함 종과 출격 준비 / 첫 식탁과 다음 제안. S07 상세는78번 보드를 재사용한다.

검수
건너뛴 후 목표 이해, 현재 선택 경로·동료·배 외형 일치, 카메라 복귀 후 조준 유지, 준비 상태 소품 일치,1막 이후 반전 사전 노출 없음. 실제 컷신·음성·이벤트 검증은 미실시다.
