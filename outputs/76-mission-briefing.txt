76. 미션 브리핑과 출항 준비 — 서명하기 전에 읽는 항해
상태: 07번 미션·08번 항로·45번 UI·64번 로안/윤·73번 철수 규칙 계승. 실제 UI 구현은 없다.

화면 흐름
게시판 선택→한 화면 요약→선택 항로→함선 점검→출항. 각 단계는 되돌아갈 수 있고 돌아와도 선택한 의뢰와 항로가 유지된다. 긴 대화를 끝내야 의뢰 내용을 볼 수 있게 하지 않는다. 로안의 인사는 첫 방문에만 자동, 상세 사연은 선택 읽기다. 항구 빠른 메뉴에서도 동일 흐름에 접근한다.

요약의 정보 우선순위
미션명과 종류, 한 문장 목표, 완료 조건, 알려진 위험, 권장 장비, 보상, 안전 귀환 조건. 권장 장비는 필수 장착과 구분한다. 특정 무기 없이 불가능하면 의뢰를 받기 전에 정확히 표시하고 지급·대여 또는 제작 경로를 제공한다. 기본 캠페인에는 무작위 희귀품을 필수로 요구하지 않는다. 미확인 적은 거짓 정확 수치 대신 ‘정찰 정보 부족’으로 표시한다.

예시 — 잔해 삼거리의 회수 의뢰
목표: 표류한 정비함을 회수해 종항으로 가져오기. 필수 완료: 정비함 적재 후 안전 경계 귀환. 선택 목표: 주변의 민간 정비정 확인. 위험: 중형 경비 비행선, 좁은 잔해 통로, 측풍. 권장: 기본 갈고리, 측면 약점에 대응할 직사 무기. 필요: 갈고리는 기본 제공이므로 별도 희귀 장비 잠금 없음. 보상 표시는 의뢰 지급과 현장 회수물을 분리한다. 구체적 지급값은18번 경제 검토 전 확정하지 않는다.

항로 선택
넓은 바깥 항로와 짧은 잔해 안쪽 항로를 지도에서 비교한다. 예상 이동 시간·연료·시야·알려진 위험·정보 출처를 표시한다. 두 항로 모두 기본 선체가 통과 가능해야 한다. 연료 예상은 날씨와 과출력 사용에 따라 바뀔 수 있는 추정임을 명시한다. 속도 높은 배만 필수 이야기 목표를 시간 안에 달성하게 만들지 않는다.

함선 점검
양력/중량, 발전/소비 전력, 기능 중인 엔진, 빈 필수 장착부, 갈고리, 현재 화물 공간, 연료 순서. 경고를 선택하면 해당 편집 부위나 보급 화면으로 이동한다. 양력과 전력은 별도 아이콘·명칭. 50번 기본 함선의 W50/L65, 소비10/발전14는 기본 프리셋 검증 예시이며 다른 함선에 그대로 복사하지 않는다.
출항 불가 조건은 필수 목표 수행 자체가 불가능한 명확한 경우에 한정한다. 선택적 위험은 이유와 복구법을 보여 주고 출항을 허용하는 후보로 둔다. 실제 허용 조건은 게임 상태 검사 구현 때 확정한다. 과적 상태에서 ‘정상’이라고 표시하지 않는다.

철수와 저장 안내
‘안전 경계로 귀환하면 확정 회수품과 조사 기록이 남습니다. 미완료 의뢰 보상은 지급되지 않습니다.’를 상세 정보에 제공한다. 패배 체크포인트 복원과 선택 철수는 별도 설명. 첫 출항 때 한 번 알려 주고 매번 강제 팝업을 띄우지 않는다. 출항 확정 시 안전 항구 상태를 저장하고 저장 실패를 알린다.

출항 연출
윤이 계류줄을 확인하고 신호기를 든다. 카메라는 짧게 배의 새 모듈을 지나 항로를 보여 준다. 건너뛰기하면 바로 조작 가능한 위치로 이동한다. 준비 연출 동안 클릭한 명령이 전투 시작 즉시 오발로 이어지지 않도록 입력 상태를 초기화한다. 마지막 지도 위치·목표 핀은 조작 시작 뒤에도 확인 가능하다.

스토리보드 6컷
1 로안과 게시판, 구조/회수/호위 의뢰의 큰 아이콘.
2 charcoal 요약 카드에 목표·위험·보상 세 구역, 읽기 쉬운 큰 글자.
3 지도 위 넓은 외곽 항로와 짧은 잔해 항로 비교.
4 귀환호 옆 점검 카드에 양력/전력/갈고리/연료, 경고가 실제 부위로 연결.
5 윤이 계류줄을 풀고 깃발을 든다. 출항 직전 마지막 확인.
6 구름으로 나아가는 비행선, 작은 목표 핀과 열린 퇴로가 함께 보인다.

검수
필수 목표와 선택 목표를 구분할 수 있는가? 권장을 필수로 오해하는가? 수리·보급 후 돌아와도 준비 선택이 남는가? 추정 연료를 보장값으로 생각하는가? 패드 포커스가 경고와 수정 메뉴를 왕복할 때 유지되는가? 실제 UI 검증은 미실시다.
