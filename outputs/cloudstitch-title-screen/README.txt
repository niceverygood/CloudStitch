Cloudstitch · 클라우드스티치
손그림 로고와 시작화면 · 2026-10-18

열어보기
index.html을 브라우저로 열면 로고, 비행선 배경, 한글 메뉴를 함께 볼 수 있습니다.
인터넷 연결과 별도 설치가 필요하지 않습니다.

최종 산출물
cloudstitch-logo.png : 투명 배경의 손그림 영문 로고. 게임 제목은 Cloudstitch로 표기합니다.
title-background.png : 메뉴와 글자를 넣지 않은 시작화면용 비행선 배경 원화.
start-screen.png : 로고와 한글 메뉴를 함께 배치한 1920 × 1080 시작화면 시안.
index.html : 시작화면과 짧은 도입 연출을 확인하는 로컬 시제품.
prompts.json / logo-cleanup-prompt.txt : 실제 사용한 생성·수정 프롬프트.
manifest.json : 이미지 크기, 투명도, 파일 목록과 제작 기록.

아트 방향
기존 귀환호의 크림색 기낭, 청록색 프로펠러와 지붕, 꿀빛 목재, 황동 장식, 산호색 수선 천을 이어받았습니다.
로고는 천에 바느질한 글자, 작은 구름, 이어지는 실을 모티브로 그렸습니다.
시작화면은 아침빛이 비치는 구름 바다에 비행선을 배치하고 왼쪽에 로고와 세로 메뉴를 두었습니다.
한글 메뉴는 이미지에 굽지 않고 HTML 텍스트로 배치해 읽기 쉽고 수정하기 편하게 구성했습니다.

시제품 동작
새로운 항해 : 기존 프롤로그 기획을 바탕으로 한 짧은 도입 패널을 엽니다.
이어하기 : 저장된 게임이 없으므로 비활성 상태입니다.
설정 : 배경 움직임을 켜거나 끕니다. 화면 하단의 버튼으로 지원되는 브라우저에서 전체화면을 전환합니다.
만든 사람들 : 제목과 짧은 작품 소개를 보여줍니다.
Tab과 방향키로 메뉴를 이동하고 Enter로 선택합니다. Escape로 열린 패널을 닫을 수 있습니다.
시작화면 및 도입 연출 시제품이며 실제 전투·저장·캠페인 실행은 포함하지 않습니다.

제작 방식
로고와 배경 원화는 내장 image_gen으로 한 호출에 한 이미지씩 생성했습니다.
로고의 독립된 작은 생성 흔적은 같은 도구의 부분 수정으로 정리했습니다.
투명 로고의 알파 채널을 보존했습니다. PNG 로고는 래스터 원화이며 벡터/SVG 로고가 아닙니다.
시작화면 PNG는 최종 HTML을 브라우저에서 실제 렌더링해 저장한 화면입니다.
HTML은 원화 두 장을 조합한 메뉴 레이아웃입니다. 외부 폰트·CDN·서버를 요청하지 않습니다.
