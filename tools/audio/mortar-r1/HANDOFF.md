# Cloudstitch 박격포 발사음 수정 r1

2026-10-18 한국 시간. 사용자가 47종 검수실에서 “박격포 소리 완전이상해”라고 평가했고, 추가 답변으로 **발사음 — ‘둔한 출발’**을 지정했다. 발사음 후보 두 개만 새로 만들었으며 낙하·착탄 및 다른 44개 후보는 변경하지 않았다.

- A: 소형 박격포의 점화 충격·강철관 압력 배출, 요청 0.65초.
- B: 같은 발사 중심에 작은 목재 받침 충격만 더한 후보, 요청 0.75초.
- 비교용 기존 소리: 기존 `fire-mortar` MP3를 SHA 대조 후 복사했다. 원본과 기존 113파일을 덮어쓰지 않았다.

기존 문안의 `poomp`, 부드러운 공기·둥근 어택이라는 표현을 빼고 점화와 발사 압력을 구체적으로 적었다. 이 문안 검토는 실제 음원을 사람이 들었다는 주장이 아니다. A·B의 음색과 정확한 단발 수 역시 사용자 검수 전이다. 원본 MP3와 실제 request/HTTP200/bytes/SHA/응답 character-cost는 `outputs/audio-mortar-r1/generation/` 및 catalog에 기록했다. 신규 요청은 2건, 성공 2건, 자동 유료 재시도 0건이다. 인증 값은 echo 없는 stdin 메모리에서만 사용했고 저장하지 않았다.

```sh
node tools/audio/mortar-r1/build.mjs --manifest
node tools/audio/mortar-r1/serve.mjs 8865
```

`http://127.0.0.1:8865/outputs/audio-mortar-r1/`에서 A·B·기존 발사음을 비교한다. 새 출력과 소스만 소유하며 기존 8864 검수실과 동결 코드는 보존한다. 서버는 127.0.0.1의 새 출력 폴더만 제공한다. 브라우저를 직접 실행하거나 다른 담당의 Native QA 슬롯과 겹치지 않았다.

비교 시 별도 decoded buffer를 peak 0.7로 맞추고 기본 음량 40%로 재생한다. 파일 원본은 수정하지 않는다. 짧은 2ms 시작/12ms 종료 fade, 단발 하나씩 재생, 정지·모노 변경·숨김·페이지 종료 때 예약/현재 소리를 정리한다. 자동 재생이나 게임 발사→피해 타임라인은 없다. A/B/둘 다 보류와 메모는 이 origin의 별도 localStorage에 저장하며 검수 JSON을 내려받을 수 있다.

`verification.json`은 새 MP3 2개+기존 1개의 압축 프레임·해시와 기존113 보존 검사다. Native decode·실제 출력·모바일·사람 청취는 별도다. `delivery-manifest.json`에는 자신의 파일을 제외한 새 소스·원본·페이지·요청·보고서·문서의 bytes/SHA를 담는다. 실제 게임 설치는 하지 않았다. 기존 권위 sim에는 박격포 고유 탄도·발사·범위 피해가 아직 연결되지 않아 검수 후보를 연결 완료로 세지 않는다.
