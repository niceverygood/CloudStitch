    귀환호 예산

    보유 자원

    총중량 = 장착 + 선내 화물 + 구조 인원. 항구 보관품은 제외합니다. 창고의 엔진·기낭은 출력을 내지 않습니다.

    저장과 재출항

    저장 실패 예시

    실제 저장소를 손상시키지 않고, 현재 세션과 마지막 성공 저장의 차이를 확인합니다.

    출항과 귀환은 버튼으로 전달하는 독립 데이터입니다. 이 화면에서 전장 이동·전투는 실행하지 않습니다.

    천 시장

    봉인 천은 별도 자원 C로 보관합니다. 이번 예시는 카탈로그의 시장 접점을 연결하며 매매·제작·봉인 기능은 후속 범위입니다.

    연결 상태
    기존 종항 그림과 카탈로그를 재사용했습니다. 브라우저 저장은 이 기기·이 주소에 속합니다. 예시 규칙 검증과 실제 항해 검증은 별도입니다. 범위와 사용 안내
