목표
크림·살구 붓결, 꿀빛 황동과 세이지 연기를 유지하면서 한 발이 공기를 밀고
선체 재료를 터뜨리는 강한 사건으로 읽힌다. 단일 크기·gain·입자 수의 배수가 아니다.
큰 주형태, 중간 곡선 덩어리, 작은 재료 반응과 시간의 대비를 새로 설계한다.

발사 사건: fire 1개에 표시 1개
- 입력 지연을 추가하지 않는다. 실제 fire 프레임에 밝은 크림색 접촉 점과
  짧게 압축된 붓결 덩어리가 즉시 보인다. 가상의 예측 사격이나 추가 탄은 만들지 않는다.
- 0~0.025초: 작은 고휘도 씨앗과 두꺼운 황동 테두리의 압축 형상.
- 0.025~0.09초: 길쭉한 단일 불꽃 대신 서로 다른 폭의 크림·살구 곡선 세 갈래가
  앞으로 벌어진다. 큰 꽃잎 형태, 안쪽 진한 붓결, 얇은 가장자리 빛을 구별한다.
- 0.07~0.22초: 뒤늦게 따라오는 두 덩어리 연기가 반대 방향으로 말린다.
  전면 섬광이 줄 때 연기가 커져 매 순간 밝은 채로 유지되는 인상을 피한다.
- 포구 위치와 축은 실제 muzzle frame이다. 무기 반동·카메라는 소유자의
  표시 feedback 한 번만 소비하며 실제 포구/aim resolver에 다시 섞지 않는다.

탄환 사건: 실제 좌표의 가독성
- 매끈한 황동 몸통·짧은 강철 탄두를 남기고, 전면 압력 고리와 후면 두 겹의
  수채화 붓꼬리를 서로 다른 길이·폭으로 배치한다. 중앙은 또렷하고 가장자리는 부드럽다.
- 중심과 +Z는 actual projectile XYZ/velocity에 직결한다. 별도 위치 보간·속도 적분·
  미리보기 비행 수명·복제 탄환은 없다. 실제 생존 중에는 유지한다.
- 후행 흔적이 필요하면 최대 4개의 실제 관측 위치를 제한된 시간/거리 안에서만
  보관한다. 순간 이동/초기화에는 비우고 잔광으로 충돌이나 명중을 추론하지 않는다.

명중 사건: 실제 contact/normal 한 개
- 0~0.025초: 법선에 붙는 작고 명확한 압착 씨앗. 탄체는 실제 종료 이벤트로 제거한다.
- 0.025~0.10초: 표면을 타고 크게 벌어지는 비대칭 3엽 붓결 주형태.
  얇은 원형 링 반복 대신 두꺼운 중심과 비어 있는 갈래 사이의 실루엣을 만든다.
- 0.06~0.22초: 바깥으로 휘는 황동색 획, 실제 표면 밖으로 퍼지는 재료 조각,
  저채도 어두운 압착층을 교차시켜 크림 섬광의 형태와 무게가 읽히게 한다.
- 0.16~0.50초: 큰 크림/세이지 연기 두 덩어리가 늦게 말리고 흩어진다.
  모든 층을 동시에 크게 키우지 않는다. 최초 타격의 빈 공간을 점차 채운다.
- 코어·표면 잔광 Mesh의 plane normal은 contact normal과 항상 평행하다.
  연기만 billboard를 사용한다. 외향 최소 간격과 depth test를 유지한다.
- 목재/도색 금속은 실제 target material tag가 제공될 때만 선택한다.
  태그 없는 대상을 임의로 목재 판정하지 않는다. 피해·구멍·파손 상태를 창작하지 않는다.

연사 리듬과 누적 긴장
- 실제 fire 간격 안에서 밝은 전면층이 먼저 접히고 다음 발의 명확한 시작을 만든다.
  연사 세 번째를 가상 추가발이나 추가명중으로 표현하지 않는다.
- 실제 fire receipt의 간격으로만 제한된 표시 강도를 계산하고 휴지 때 빠르게 감쇠한다.
  큰 빛을 계속 켜는 대신 곡선 방향·연기 높이·파편 강조의 결정적 변주를 사용한다.
- 실제 hit receipt가 있을 때만 접촉 강조를 더한다. 빗나감은 포구/비행만 보인다.
- 발사음/명중음은 음향 담당의 한 이벤트 경로다. 이 모듈은 소리를 직접 중복 재생하지 않는다.

유지할 기술 계약
단일 sim 시간, 이벤트/ID/generation 중복 방지, pause dt0, retry/clear/dispose,
동시 표시·풀·최근 영수증 상한, caller atlas 소유권, reducedMotion/조준/UI 가독성을 유지한다.
HP·탄·쿨다운·속도·충돌 범위·무기 수·견인·캠페인 규칙 변경은 0이다.
기존 machine-gun-soft-v1/soft-runtime READY1과 원 atlas·기존 FAIL/PASS를 원바이트 보존한다.

실제 전후 비교 계획
같은 실제 한 발의 muzzle frame/trajectory/contact normal, 같은 카메라/배치,
같은 sim 시간에서 기존 soft와 dramatic을 나란히 본다. 포구 0.035/0.11초,
비행 실제 중간 좌표, 명중 0.035/0.10/0.24/0.45초 및 실제 연사를 기록한다.
콜리전 없는 miss와 실제 hit를 구별하고 세 표시 모드/카메라/모바일도 본다.
기술 동작 PASS, 최신 대담함 목표의 실제 제시, 사람의 미술/타격감 승인을 구분한다.

아직 미완
이 문서는 방향 설계다. 새 layer 구현, 타이밍 프로파일, 동일 조건의 실제 전후 렌더,
음량을 맞춘 음향 비교와 사람의 체감 확인은 수행하지 않았다.
현재 soft-runtime READY1의 실전 연결과 검수는 별도 진행 중이다.
이미지/3D/유료 생성, 새로운 서버·브라우저·전체 재생성은 이 설계로 시작하지 않는다.
