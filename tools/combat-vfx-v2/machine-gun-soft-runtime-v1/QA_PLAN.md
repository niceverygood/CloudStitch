# 실전 연결 검수 범위

통합 단일 브라우저 슬롯에서 새 실제 전투 진입점을 사용한다. 효과만 시간을 이동시키는 이전 미리보기와 CPU 검사 결과는 실제 플레이 증거와 구별한다.

1. 로컬 atlas 두 장과 실제 선택선·적 모델이 로드되고 페이지/콘솔 오류가 없는지 확인한다. 기관총에는 soft renderer 하나, 다른 무기에는 기존 또는 소유자의 새 renderer만 붙는다.
2. 실제 입력으로 한 발 쏜다. 실제 muzzle frame에서 크림 섬광이 한 번 나오고 탄환 root가 sim의 매 프레임 XYZ와 일치하는지 기록한다. 0.45초를 넘는 실제 비행에서도 탄환은 임의로 사라지지 않는다.
3. 실제 충돌이 발생한 프레임에만 부드러운 피격 코어·잔광·연기가 나오고 피해는 한 번 적용되는지 확인한다. hit 위치/normal, 탄환 제거, 표시 hit counter를 함께 기록한다. 코어와 여섯 잔광은 카메라를 바꿔도 명중면과 평행해야 한다.
4. 빈 곳에 쏘거나 사거리 밖으로 사라진 탄환에는 피격 효과/피해가 없는지 확인한다. 같은 이벤트의 반복 소비에도 중복 섬광·명중이 없어야 한다.
5. 비행 중 일시정지에서 탄환·효과 나이가 멈추고 재개하면 이어지는지, 재시도/새 항해 시 이전 탄·연기·이벤트가 남지 않는지 확인한다. 전투 정리/귀환/패배도 남은 표시를 없앤다.
6. 화면 맞춤·카메라 회전·휠 확대와 모바일 폭에서 장면·조작 UI가 사용 가능하고, 윤곽 렌더에 잔상이 없는지 확인한다. OutlineEffect.autoClear=true를 유지한다.

실제 브라우저 보고서에는 사용한 source/import manifest SHA, 실제 URL, 실행 입력/사례, 캡처와 실패를 기록한다. 카메라 반동·새 함포 등의 다른 변경을 결합할 경우 그 검증은 전장 소유자 범위로 별도 표시한다. 스타일에 대한 사람의 최종 승인은 자동 검사로 선언하지 않는다.
