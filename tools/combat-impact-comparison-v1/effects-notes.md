# Dramatic effects implementation

Latest direction: 10배 이상 대담한 수공예 판타지, 손그림처럼 보이는 입체 3D. This is an original code asset. No paid generation, browser, server, shared source or original assets changed.

`createDramaticEffects(THREE, scene, {weapon,atlas,reducedMotion})` exports the agreed API. `mg`, `machine-gun`, `01-machine-gun` select the short, sharp MG profile; other values select cannon. Events use absolute seconds and world positions; hit normal points out of the target. Projectile direction is forward. Atlas is optional and remains caller-owned; current rendering uses vertex-colored procedural geometry so it does not require a texture or light rig.

Large irregular cream heart and apricot shell release into five curved, asymmetric brush petals. A dark compressed foot separates the white core from a pale background. Gold hooks bend out before sage smoke rises and expands. Material-shaped chips appear only at hits; these are generic illustrative fragments, not claims about target material or actual destruction. Cannon spreads an expansive, slow billow; MG snaps and clears quickly. Fixed curved meshes, warped blobs, tonal vertex brush bands and staggered births replace soft repeated atlas dots. Strong impact forms, medium gas folds and fine splinters have different silhouettes and timing. No arbitrary extra attacks or hit events are generated.

`update(time, fullEventHistory, projectileSnapshot, camera)` clears visibility and reconstructs the same pose from absolute time. Scrubbing and repeat calls do not allocate geometry or integrate projectile positions. Flight center follows the supplied position exactly; broad curved painted tails are decorative geometry behind that center, not predicted paths. Camera is accepted for API compatibility; forms are 3D and do not require camera-facing planes. Impact local +Y aligns with contact normal; muzzle local +Y aligns with direction. Reduced motion lowers debris travel and smoke drift while preserving a readable event.

Fixed pools: 32 event slots, 32 projectile slots; at most 22 render meshes per event slot and 5 per projectile slot. Event lifetime caps: cannon hit 1.65s / muzzle .65s, MG hit .72s / muzzle .30s. Excess events keep latest 32; projectile input keeps first 32. Exact same type/id/time receipts deduplicate per update. All geometry and owned materials are released by dispose; injected atlas is never disposed. No audio, camera impulse, gameplay mutation or damage changes.

Source/syntax and deterministic pose checks are separate from browser render QA and human art approval. Identical-camera old/new fire, travel and hit playback still requires central integration QA. This implementation alone does not establish the user's artistic approval.
