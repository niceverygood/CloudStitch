Cloudstitch(클라우드스티치) 프로젝트를 이 데스크톱에서 이어서 작업해줘.

저장소: https://github.com/niceverygood/CloudStitch.git
이전 컴퓨터의 로컬 포트59306이나 절대 경로가 이 PC에도 있다고 가정하지 마.

처음 받는 PC에서는 Git과 Git LFS를 준비한 뒤 실행해:
git lfs install
git clone https://github.com/niceverygood/CloudStitch.git
cd CloudStitch
git lfs pull

이미 저장소가 있으면 git status로 기존 수정을 먼저 보존하고, 작업 트리가 깨끗할 때 git pull --ff-only와 git lfs pull로 최신 main을 받아줘. 수정이 있으면 임의로 reset/stash/drop하지 말고 충돌 없는 방법으로 보존해줘.

AGENTS.md, README.md, docs/HANDOFF.md, docs/DESKTOP_HANDOFF-2026-10-18.md를 먼저 읽어줘. 과거 문서의 '전투 구현 없음'과 현재 추가된 브라우저 전장 시제품을 구분해줘.

현재 자료:
1. outputs/fleet-v1/index.html: 기존 실제 비행선 GLB71항목 제작판. 고유 정사 함선71종이라는 뜻은 아니야.
2. outputs/battlefield-v1/index.html: 이번 세션의 첫 전장. 9개 부유섬과 귀환 부두, 귀환호+적선3종 실제 GLB, 이동/기관총/적 포격 예고/연결부 절단/하위 묶음 분리/인양·소유권·화물/과적·투하/부두 귀환이 있어. 소스는 tools/battlefield/야.
3. outputs/encounters-v1/: 다른 세션의6판 일반전·중간보스·최종보스 교전 시제품이야. battlefield-v1과 별도 구현이므로 무단 덮어쓰기나 합치기를 하지 말고 실제 README·manifest·검사 기록으로 상태를 확인해줘.
4. outputs/weapon-workbench, outputs/combat-vfx, outputs/world-assets: 원격에 먼저 올라온 별도 에셋 자료야. 새로 생성하지 말고 현재 파일의 제작/검사/한계를 확인해줘.

실행 준비와 첫 전장 검사:
npm ci
node tools/battlefield/build.cjs
node --test tools/battlefield/sim.test.mjs
python -m http.server 8080 --bind 127.0.0.1

브라우저에서 http://127.0.0.1:8080/outputs/battlefield-v1/index.html 을 열어줘. macOS/Linux에서 python 명령이 없다면 python3을 사용해. HTTP로 저장소 루트를 제공해야 GLB 상대 경로가 동작해. file://로 직접 열지 마.

브라우저 자동 검사도 필요하면 npm run setup:browser로 Chromium을 준비하고, BATTLEFIELD_URL 환경변수에 실제 로컬 주소를 넣어 node tools/battlefield/verify.cjs를 실행해. 환경변수 설정 문법은 현재 PC의 셸에 맞춰줘. 저장된 검사 결과는 outputs/battlefield-v1/verification.json, 재검사 화면과 로그는 work/verification/battlefield/에 있어.

조작: WASD/방향키 이동, Space 가속, 마우스 조준/클릭 사격, 기관총 버튼 길게 누르면 자동 조준, Tab 표적 전환, F 인양, H 남쪽 부두 귀환, M 전체 항로, 휠 확대, Esc 멈춤. 모바일은 터치 스틱과 동작 버튼.

확정 조건: 공식명 Cloudstitch. 크림색 기낭·꿀빛 목재·청록 기계·황동·산호색 수선 천의 감성적인 손그림 방향. 특정 엔진/최종 플랫폼/성능 예산은 미정이야. 기존 GLB·원화·기획·생성 이력은 보존해. 유료 생성·외부 배포·예약 자동화·별도 채팅은 임의로 실행하지 마.

한계: 첫 전장은 임시 평면 충돌과 시험 수치야. 인양은 화물 적재이고 장착이 아니야. 장착 편집, 전체 항구경제/정산, 영속저장, 캠페인, 패드, 무기별 완성 효과는 없어. 새로고침하면 초기화돼. 에셋·파일·자동 검사 통과를 실제 기기 성능이나 재미 검증으로 과장하지 마. OutlineEffect.autoClear=true를 유지해.

먼저 최신 파일을 받아 실제 첫 전장을 열고 조작·사격·분리·인양·귀환 상태를 재확인해줘. 현재 결과와 남은 작업을 한국어로 간결하게 정리한 뒤, 내가 지정하는 다음 작업을 이어가줘.
