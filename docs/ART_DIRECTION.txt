Cloudstitch 상시 아트·사운드·타격감 디렉션
적용일: 2026-10-18 / 모든 현재·신규 프로젝트 세션의 제작·수정·프롬프트·검수 기본값
사용자의 최신 직접 요청이 이 기준보다 우선한다.

사용자 확정
최신 강화 요청: “게임 이미지 에셋도 그렇고 음향효과나 피격&공격 효과도 그렇게 너무 평범하게 만들고 있어 훨씬 과하고, 극적이고, 풍성하게 만들어져야 손맛, 타격감, 게임성이 살아나 모든 세션에 명심하게 만들어줘 그냥 현재보다 2~3배 정도 과하게가 아니라 10배 이상 과감해져야해”
이 최신 강도 기준이 아래 이전 요청의 ‘약간/조금/한 단계’ 표현보다 우선한다.
“모든 세션에서 에셋을 만들때(비행선, 마을, 기지, 이팩트 효과 등등) 하울의 움직이는 성 느낌의 감성과 2d느낌의 3d 효과가 느껴지게 만들게 해줘 전체 룰로 적용될수 있게 지시해줘 내가 앞으로 따로 언급하지 않아도”
“모든 에셋은 단조롭지 않고 약간 과하고 글래머러스하게 표현되게 만들어줘”

공통 방향
따뜻한 수공예 판타지, 살아 있는 기계와 생활의 흔적, 구름 위의 낭만을 지향한다.
실제 3D의 입체 구조와 회전 가능한 부피 위에 손그림 색·붓결·단순 명암·윤곽을 얹는다.
이미지·모델·환경·음향·공격/피격·폭발·움직임 모두 현재보다 10배 이상 과감하고, 극적이고, 풍성하게 설계한다.
10배는 표현의 대담함과 체감 목표이며 단일 scale/gain/입자 수·피해 수치의 배수가 아니다.
형태·볼륨·구조·재료·색·시간·소리의 여러 층을 함께 설계해 이전의 평범한 인상이 명확히 달라지게 만든다.
독자적인 디자인으로 구현하며 영화의 고유 캐릭터·성·문양·로고·장면을 그대로 재현하지 않는다.

강화 기준: 모든 세션의 제작·검수 기본값
- ‘조금 더/2~3배’에서 멈추지 않는다. 강한 주형태와 크게 다른 실루엣·질량·비대칭·높이차·겹구조·풍성한 부속으로 독자적인 존재감을 만든다.
- 작은 도형을 많이 붙이는 것만으로 밀도를 채우지 않는다. 큰 형태, 중간 기능 덩어리, 작은 생활 디테일의 계층을 만든다.
- 공격은 예비 동작→발사·가속→접촉→분출·충격→잔해·연기·여운의 변화와 리듬을 설계한다. 매순간 같은 세기의 섬광을 켜두지 않는다.
- 명중 순간은 주형태·재료 파열·방향성 충격·파편/불씨·후속 연기, 반동/선택적 카메라 반응과 소리가 하나의 사건으로 읽히게 한다.
- 무기·재료·공격 강도별 개성을 만든다. 연사는 또렷한 반복과 누적 긴장감, 중화기는 무게와 큰 해방감, 보스는 압도적인 규모와 전조로 구분한다.
- 풍부한 세계와 강렬한 전투를 모두 손그림 같은 입체3D로 이어간다. 조용한 생활 장면과 강한 사건의 대비를 사용한다.
- 제작 프롬프트/소스 프로파일/HANDOFF에 최신 ‘10배 이상 과감함’과 적용한 구체 형태·층·시간·재료·리듬을 적는다.

음향과 손맛
- 발음 첫 윤곽, 충격 몸통, 나무/금속/천/기계의 재료 반응, 저중역 울림, 파열·잔해·기계/공간 잔향과 종료를 함께 설계한다.
- 소스의 음고·길이·질감·폭과 층의 출입·간격을 적극적으로 바꿔 무기별 정체성과 극적인 순간을 만든다. gain/EQ 증가만으로 새 요구 완료라고 하지 않는다.
- 실제 발사·비행·충돌·피격·종료 이벤트와 시각/음을 맞춘다. 시연 타임라인과 실제 판정·상태 변화를 구분한다.
- 연사 간격과 중첩 한도, 중지/release·loop·pause/reset/dispose, 유한 PCM과 헤드룸을 검증한다. 강한 표현을 단순한 과출력으로 만들지 않는다.
- 새/구본의 같은 이벤트를 직접 듣고 음량을 맞춘 비교도 제공한다. peak/RMS/검사 개수는 사용자의 청감 승인과 구분한다.

비교와 완료 기준
- 대표 새 결과를 기존 결과와 같은 카메라·배치·애니메이션 시점/이벤트 조건으로 나란히 제시한다. 실제 움직임과 실제 음향의 전후 차이를 확인한다.
- 큰 형태·중간 기능·작은 재료층, 전조·접촉·분출·여운, 무기별 개성·리듬이 어떻게 바뀌었는지 짧게 기록한다.
- 이전 결과의 작은 증폭판처럼 느껴지면 소유자가 표현을 다시 설계한다. 큰 scale/gain 하나 또는 ‘10배’ 문구만으로 통과시키지 않는다.
- 기존 기술 PASS는 원 revision의 증거다. 앞서 만든 2~3배 강화판을 최신 10배 지시의 최종 이행으로 바꾸어 표시하지 않는다.
- 통합 QA는 기술 동작과 새 표현의 실제 제시를 확인하고, 사람의 미술·청감·손맛 승인 대기는 명시한다.

형태와 밀도
- 큰 덩어리의 매력적인 비율과 강한 실루엣을 먼저 잡고, 겹겹의 구조와 부속 장치로 깊이를 만든다.
- 적당한 비대칭, 과장된 기낭·지붕·선수·크레인·프로펠러·연통 등 역할을 설명하는 특징을 쓴다.
- 황동 테두리, 밧줄, 봉제선, 수선 천, 파이프, 작은 창·등·차양·표지 같은 생활 디테일을 겹친다.
- 서로 다른 종류는 구조·비율·기능 장치도 다르게 만든다. 같은 함선의 단계 변화는 원래 정체성을 유지한다.
- 모든 면을 같은 밀도로 채우지 않는다. 큰 면과 쉬는 공간이 풍성한 장식과 함께 읽히게 구성한다.
- 장식이나 포대의 시각적 수량은 아트 해석이다. 실제 modules/슬롯/무장 수·성능·장비 규칙으로 자동 채택하지 않는다.

재료·색·빛
- 목재·직물·황동·도색 금속의 재료 차이를 따뜻한 색과 붓결로 표현한다.
- 크림·꿀빛 목재·청록·산호색 수선 천의 기존 선택선 정체성과 기존 아트 기준 이미지를 보존한다.
- 적 세력의 먹색 판금·회색 천·청록 잔광 등 고유 팔레트도 살린다. 모든 세력을 같은 색으로 통일하지 않는다.
- 단순하고 부드러운 명암, 읽기 쉬운 선, 선택적 하이라이트로 그림 같은 입체감을 만든다.
- 사실적인 PBR 광택·번쩍이는 플라스틱 표면만으로 화려함을 만들지 않는다.
- GLB의 재질/텍스처와 뷰어 런타임의 셀 명암·윤곽선 역할을 구분해 인계한다.

대상별 적용
- 비행선·탈것: 풍성한 기낭과 독특한 선체, 여러 높이의 갑판/공방·깃발·동력 장치로 정체성을 만든다.
- 마을·기지·건물: 서로 다른 높이의 덩어리, 겹지붕·굴뚝·배관·발코니·차양·등과 생활 흔적으로 입체적인 마을감을 만든다.
- 무기·소품: 큰 기능 형태와 손잡이/레버/황동/천 등 재료의 대비를 쓴다. 작은 화면에서도 역할을 먼저 읽힌다.
- 이펙트: 붓터치 같은 덩어리, 부드럽게 말리는 연기, 빛·불씨·잔광·잔해의 여러 층과 풍부한 리듬을 쓴다.
- 움직임: 예비 동작, 부유·관성·살짝 늦게 따라오는 부속, 흔들린 뒤 감쇠되는 움직임으로 생동감을 준다.
- 단계별 전시: 피해·성장·장갑·무기·폭발의 차이가 한눈에 보이게 한다. 시각 제안과 실제 게임 상태를 구분한다.

가독성과 실제 검수
풍성함과 함께 선체·무기·명중면·약점·조준점·UI의 가독성을 유지한다.
실제 대표 렌더에서 큰 실루엣, 재료/붓결, 층과 부피, 단계별 차이, 효과 방향/시간을 확인한다.
체크리스트 문구만으로 스타일 충족이나 사람의 미술 승인을 선언하지 않는다.
뷰어를 변경하면 AGENTS.md의 실제 GLB/세 모드/윤곽/조작/모바일/외부 요청/잔상 확인을 적용한다.
새 아트 때문에 sim 피해량·충돌체·장착·저장·캠페인 규칙을 임의 변경하지 않는다.

작업·인계 적용
- 앞으로 새 에셋을 만들거나 수정할 때 사용자가 반복 언급하지 않아도 이 기준을 읽고 적용한다.
- 생성 프롬프트에는 위 공통 방향과 해당 대상의 형태/재료/움직임 특징을 구체적으로 포함한다.
- 새 제작물과 진행 중인 수정에 우선 적용한다. 동결된 자산·이전 비교본·원화는 유지하고 변경은 새 revision으로 남긴다.
- 규칙을 등록하는 작업은 기존 수백 자산 일괄 재생성, 새 유료 호출, 별도 자동화나 게임 자동 설치 요청이 아니다.
- 담당 파일 경계/브라우저 슬롯/READY manifest/통합 QA는 outputs/project-command/COORDINATION.txt를 따른다.
- 소유자 HANDOFF에 최신 10배 기준, 적용한 형태·재료·소리·시간/표현, 실제 전후 비교, 아직 미완인 부분을 짧게 적는다.
